## 2. 最终方案

配置名 `A6-F-A5f0.05-A4-GH0.5`，权重 `save/forecasting/ntu120_label/ntu2p_v2_A6-F-A5f0.05-A4-GH0.5_s{0,1,2}_10000/ema/model000010000.pt`。模型 3.65M 参数，旧主线为冻结 base 5.6M + refiner 7.1M。

| 组成 | 作用 | 与 ReGenNet 的关系 |
|---|---|---|
| **A6 InterMixer**（`model/forecasting_ntu2p_intermixer.py`） | 端到端、场景规范系的双人 DCT-Mixer，取代"冻结单人 base + 残差 refiner" | 复用施动/受动顺序（role embedding，不做 A/B 交换）；跨人信息在规范系中表达为相对几何 |
| 块结构 | 时间（DCT 系数轴）混合 + 通道 MLP + 零初始化人物混合 + 动作 FiLM | — |
| 输出 | root 低阶 DCT（8 阶）+ 局部中阶 DCT（20 阶），乘 saturate ramp，首帧恒等于观测末帧 | — |
| 刚体手 | 每只手每帧只预测一个旋转 | 对应 ReGenNet SMPL-X 运动学表示的"合法人体"优点 |
| **F** 规范系回退（`canonical_ab_fallback=camera_x`） | 双人重合时 yaw 回退到相机 x 轴 | — |
| **A5** 脚接触损失 w=0.05 | GT 站定帧上惩罚预测脚的水平速度；A6 收敛态下约占总 loss 5% | — |
| **A4** 可微骨架投影 | 骨长取观测末帧；四肢用两骨 IK，多子节点关节用 Procrustes；骨长误差恒为 0 | 对应 ReGenNet 的 FK 表示：输出永远是合法人体，但不走 rot6d 扩散 |
| **GH** 腿部专用流 + 相位敏感腿部损失 w=0.5 | 在个人朝向系中直接读腿部运动学，以主干 root 为条件；腿局部位置 + ≤2 Hz 低通速度 MSE；腿移出 DCT 中频幅度损失 | — |

## 4. 筛选过程与各因素的作用

val，逐 seed 配对。完整表格见 `results/forecasting/ntu120_label/ntu2p_v2_screen/summary_10000.md`。

| 阶段 | 配置 | val mpjpe | 结论 |
|---|---|---:|---|
| Stage 1 | A1 规范系 refiner | 0.1733 | mpjpe −0.8%，mse 升（由样本 125 造成） |
| | A2 规范系 + 解冻 base | 0.1711 | −2.0% |
| | A3 规范系 + 检索锚点 | 0.1708 | −2.2%，但只比免训练的"事后 root 混合"（0.1710）好 0.17%，不值得其复杂度 |
| | **A6 InterMixer** | **0.1646** | **−5.75%，mse −13%**；步行脚速被否决 |
| Stage 2 | A6-F（回退修复） | 0.1635 | 修复一个损坏样本，mse 与 mpjpe 均降 |
| | A6-F-A4 骨架投影 | 0.1634 | 骨长误差 → 0，L2 中性 |
| | **A6-F-A5f0.05** 脚接触 | **0.1613** | L2 −1.4%，步行脚速减半；但审查图显示腿被拉长（最坏近 2 倍） |
| | A6-F-A5f0.2 | 0.1627 | 自然度更强、L2 较差；腿更僵、少走 |
| | A6-F-A7 镜像增广 | 0.1615 | L2 −1.2%，但叠在 A5 上无增益 |
| Stage 3 | A6-F-A5f0.05-A4 | 0.1626 | A4 在 A5 上有 +0.8% 代价；腿不再被拉长，但出现"弓步前滑" |
| 步态 | A5-A4 + GL0.5 | 0.1602 | 相位相关 f1-10 0.01 → 0.50 |
| | **A5-A4 + GH0.5** | **0.1610** | 相位相关 f1-10 0.01 → 0.57，步数 0.18 → 1.49 |

关键诊断：
1. **退化样本**：val 样本 125 的观测是损坏的（A 连续 9 帧冻结、B 与 A 身份混淆），两人 pelvis 只相距 0.01 m。规范系原本回退为"A 的朝向"，在该样本上把预测转了约 90°。单个样本就让 mpjpe 移动 1–1.4%。修复（F）只影响 val 1 条、test 2 条。
2. **腿不迈步的根因**：在 A6 的 loss 中，手指占 81%、腿占 7.7%；输出头 96% 的梯度落在手腕通道，腿只有 0.5%。腿仅有的梯度 79% 来自与相位无关的 DCT 中频幅度项，在腿上产生 1.2–2 Hz、与 GT 无关的摆动，而 NTU 步态 99% 的能量在 ≤1 Hz。
3. **相位可以预测**：只看腿部 8 个关节的小 MLP，对观测中已在走的人，f11-20 相关达到 0.92（A6 为 0.44）。因此这是学习问题，而不是内在不确定性。
4. **平均骨长误差会掩盖肢体拉伸**：直接输出 xyz 的模型在步行时，腿骨在个别帧被拉长到接近 2 倍（A6-F：步行者最大骨长偏差的均值为 92%），平均骨长误差却只有约 5%。最终方案用 A4 从结构上消除了这个问题。

## 5. 视觉审查

审查图：`results/forecasting/ntu120_label/ntu2p_v2_screen/review_{stage1,stage2,stage3,gait}/sheets/`（val）；test 在 `results/forecasting/ntu120_label/ntu2p_v2_final_gh/test_review/`，每例都有审查图、mp4 三色视频，以及视频抽帧网格 `*_grid.png`。

- **val 步行**：
  - walk_070、walk_096、walk_011、walk_065 中，GH 的左右踝前后分离都按 GT 的顺序完成了 1–2 次交替，俯视图是离散的环状落脚点。
  - A0、A6、A5-A4 在同样案例里曲线不变号，足迹是连续拖痕。其中 A5 系列有"腿被拉长 / 弓步前滑"。
  - walk_065 是一个从站立起步的案例：只有 GH 迈了步。
- **val 非步行**：rand_124（摸口袋）中 GH 双脚踩实，左右腿分离恒定且与 GT 一致，mpjpe 在各方法中最低。
- **test 视频抽帧**：
  - walk_444（走向对方）：前 1.2 s 与 GT 重合、迈步姿态自然，之后步频慢于 GT。
  - walk_1174（跟随）：GT 本身在第 30 帧后出现骨架倒地的跟踪失败，GH 输出保持直立，腿部一前一后。
  - rand_082（出拳）：GH 全程紧贴 GT，双脚踩实，出拳手臂的伸展幅度小于 GT，属于确定性回归的均值化。
- **结论**：没有看到"分数高但腿不迈步、整体漂移"或肢体变形。残留问题是步频偏慢、出拳幅度偏小。

## 6. 与预登记规则的偏离（如实记录）

1. **步态规则中的"滑行帧比 ≤ 1.10 × 参照"护栏**：GH 为参照 A6-F-A5f0.05-A4 的 1.83 倍，GL 为 2.37 倍，按规则两者都"不采纳"，其余主判据与 L2 护栏全部通过。
   - 仍然采纳 GH 的理由：参照的滑行帧比低（0.12），是因为它的腿几乎不动（步数 0.18），脚钉地而骨盆前移，也就是审查图中的弓步前滑，这个指标在那里并不反映自然。
   - 设计 4.2 原本的否决项以 A0 为参照：GH 在 val 上通过（0.219 vs 0.261）。
   - 在 test 上 GH 的滑行帧比比 A0 高 16%（0.249 vs 0.214），**超过了 10% 的否决线**，这是 GH 的真实局限。原因是腿动得多了，但步频慢于 GT，部分帧脚与骨盆一起平移。其余自然度指标在 test 上都明显优于 A0。
   - 采纳依据是规则 C（审查图）加上多数自然度指标的一致改善。这是一次需要用户知悉的判断。
2. **筛选步数**：从 5000 改为 10000，理由见实现文档：5000 step 的 seed 噪声约为采纳阈值的 3 倍。
3. **回退修复 F**：在看过 val 失败样本之后才加入。它是对回退分支定义的修正，不是可调参数；test 从未参与选择。

## 7. 局限与下一步

- **val 与 test 的收益差距**：val −7.8%，test −3.85%。val 的 42 个受试者全部在 train 中，端到端模型可能更能利用受试者重叠。以后选型应更重视 test 同分布的留出受试者验证，例如从 train 中留出受试者作 val。
- **步频偏慢**：test 步数 1.34，GT 为 2.19。从站立起步的人相位本质上多模态，上界相关只有约 0.4。可交给 Track B（以 GH 为确定性底座的残差生成模型）。
- **滑行帧比在 test 上略差于 A0**。可试的方向：手指损失去重（α=1/15），把梯度更多地还给身体；或自洽的脚锁定。
- **未采纳的部件**：检索锚点（A3）与镜像增广（A7）的代码保留，开关默认关闭。
