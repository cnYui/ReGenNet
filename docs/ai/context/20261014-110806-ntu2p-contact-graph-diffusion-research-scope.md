# NTU2P 接触图与步态扩散：研究范围

## 用户目标与授权

用户要求自主研究、修改模型、比较多个架构并给出实际优化结果；保留 DCT，融入原 ReGenNet 的扩散组件，改善左右腿交替迈步与手—身体接触后反应时序。本轮按该授权连续完成研究、设计、实现、训练、审查与结果归档。使用 using-superpowers 的先设计后实现约束；文献核查使用 deep-research quick 模式。

## 研究问题

在 NTU 双人 obs10/future50 的受试者留出验证协议中，接触状态条件化的频域图去噪架构能否提升运动预测的综合质量？

子问题：
1. 动态手—身体图是否减少推人类动作的提前后退与接触距离误差？
2. 左右腿相位条件与接触监督是否提升交替步态并降低自身脚滑？
3. DCT 表示结合 ReGenNet 扩散训练是否优于相同底座与预算的确定性对照？

FINER 主问题：可行 4、兴趣 5、新颖 3、伦理 5、相关 5，均分 4.4。新颖性暂评 3，必须核查现有文献，不预先宣称首创。

候选问题：仅换 DCT 为新算子（均分 3.2，不直接针对失败）；仅加入图注意力（4.0，不能保证事件时序）；接触与步态条件化频域去噪（4.4，本轮采用）。

## 边界与必须保留的约束

- 数据：真实双人 xyz，26 类动作标签，固定 obs10/future50；保留首预测帧连续性与可微骨架投影。
- 参照：当前 v2+FD2，另报告 independent base 和 copy-last；主指标为 paired xyz_mse/xyz_mae/mpjpe，并同步报告步态、自然度与接触时序。
- 选型：subject-holdout val；禁止用 test 选架构、挑 checkpoint 或按 GT 挑样声称点预测提高。
- 训练：显式 cuda:0；单张 RTX 3080 10GB，按实测显存安排候选并发，不干扰已有 GPU 作业。
- 文献：官方论文/会议页/arXiv 原文优先，记录 URL、检索日期、论断依据与近邻工作；未验证来源不进入结论。
- 接触解释：只有数据确实支持接触导致反应的窗口才能评价“接触后后退”；提前避让可能合法，不能把所有动作硬锁死。
- 科学边界：骨架拟合不含真实皮肤表面或力传感器；骨架距离是接触代理，不能等同真实物理因果证据。
- 历史 Track B 不采纳的残差扩散不得换名复跑；新方案需明确解决其起步突跳、弓步、脚滑、概率质量问题。
