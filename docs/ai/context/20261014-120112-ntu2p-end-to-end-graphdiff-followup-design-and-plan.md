# 冻结纠正器筛选后的端到端图扩散设计与计划

## 已有终点证据与新假设

C1–C4 已在 H-val 完成 seed0×5000。对照 FD2 mpjpe 0.172229；四组为 0.171175/0.171238/0.171238/0.171228，改善0.57–0.61%，都未达到原采纳规则。步数约1.46→1.47，滑行约0.200→0.198–0.199，推人距离RMSE约0.203→0.204；不能归因为接触图或扩散有效。

新假设是冻结底座限制了监督向原 root/腿/手通道传播。残差表示的 oracle 容量已充足，因此不扩大 DCT 阶数、不改接触阈值或采纳线；让整个可学习预测路径共同优化，检验这一假设。它不是“必须成功”的解释，也不消除未来多模态与接触标签稀少的问题。

## 必须保持的约束

- 受试者留出 H-val，原协议 test 不参与本轮；EMA终点，禁止挑 checkpoint。
- 原 C1–C4 已有权重、配置、结果和模型默认行为完整保留；新增配置 `fine_tune_prior` 默认关闭。
- 端到端模型另存一份原 FD2 reference，永久冻结，评估的 `prior` 指标必须来自这份原模型。不能把已经改过的底座冒充对照。
- 图仍是信息交换，腿分支仍是专用系数头；没有显式相位状态机，没有接触前禁止自主后退的硬保证。
- 随机 C4 评价与本阶段独立完成；联合训练带来点预测收益也不能自动证明随机扩散概率质量。

## 架构与训练矩阵

复用已有规范系/图/DCT纠正器/骨架投影。原 InterMixer 参数解冻，新纠正器参数正常训练。编码未来残差目标时仍停止梯度，点轨迹与几何特征允许梯度传到 InterMixer。reference 在 train 模式始终 eval、无梯度。

| 代号 | 结构 | 验证 |
|---|---|---|
| F1 | 端到端时间纠正器，图/腿专用流/加噪关闭 | 新监督、额外训练与容量对照 |
| F2 | F1 + 图 + 腿专用流 | 联合结构是否优于相同训练的对照 |
| F3 | F2 + ReGenNet q_sample 去噪 | 扩散的同预算增量 |

三者从同一个同seed FD2 checkpoint及相同纠正器初始化开始；所有参数集合相同，全部两次纠正器forward、相同损失/随机流/数据采样/EMA。新头lr3e-4，原InterMixer lr3e-5（固定0.1倍），batch8，AdamW及原正则不变。先5000×seed0，同一3080并发2组；实际吞吐由新200step冒烟记录。候选之间只改变图/腿流及前向加噪，不加入增广、标签重采样或新增自然度损失。

至多选择一个过原采纳规则的配置，从原FD2重新开始10000×3seed；报告EMA终点均值±标准差。三seed与固定视觉审查通过后才能原协议10000×3seed并一次test。所有筛选失败则停止此联合训练方向，完整保留负结果，不通过调宽判据采纳。

## 实施顺序与必要验证

1. 默认兼容的配置与reference保存/加载，优化器分组；新增F候选与独立run目录。
2. 验证旧C checkpoint预测不变；F参数初始化相同；原底座有有限非零梯度、reference无梯度且权重不变；新增头仍有梯度；checkpoint复载；EMA/reference语义。
3. CUDA200step冒烟与完整三候选筛选，沿用已有终点评价及预固定18案例+GT随机6起步扩展，另全部12推人曲线。
4. 原采纳规则下复现或拒绝。若收益只有F1，归于联合训练/监督，不能声称图或扩散贡献；F3必须超过F2才能声称扩散改善点预测。

接触控制器可行性另见`20261014-114724-ntu2p-event-controller-feasibility-plan.md`。固定门诊断已有推人子集精度退化，不能把它作为本阶段部署修复；必须先解决手部到达、路线辨别与root/脚耦合。该结果不被删除或改成成功案例。
