# NTU2P 接触图扩散：反证审查 Checkpoint 2 与独立评价修订计划

审查对象：`20261014-113727-ntu2p-contact-graph-phase-diffusion-research-brief.md`，及当前 graphdiff 模型、训练、候选驱动与随机评价。采用 deep-research 的 devils_advocate_agent Checkpoint 2，对文献综合与证据链进行独立反证。新候选完整训练结果不属于此简报，最终结果还需另行审查。

## Verdict：REVISE

没有 Critical。官方原文支持的近邻机制与“DCT 年代不决定预测价值”的结论成立；简报没有把跨任务论文成绩冒充本项目优化数字，也没有声称首创。当前有一项实测方法口径差异，及两项需要缩小的机制/概率表述。父代理已同意修订独立评价代码，冻结正在训练的网络与损失；不覆写历史文档或 C1/C2/采样冒烟产物。

## Critical

无。contact proxy 不等于真实皮肤接触、两方 future 未知、t999/零输入为明确监督点部署、in-sample 残差随机模式探索性等关键边界均已披露。

## Major

### DA2-1：审计接触代理与正式模型代理不同，离散数字不可直接衔接

- 类型：方法/证据。
- 位置：简报“问题与证据”的 4/4/4/3 及后退提前 0.16–0.23 s；audit_contact_gait.py 与 utils/ntu2p_contact_graph.py。
- 根因：审计用 wrist/index1/pinky1 三点均值，躯干 5 段含肩横线(16,17)；正式 helper 用腕与 index1/pinky1 中点两处取更近，6 段以(9,16)/(9,17)代替肩横线。同一阈值不能表示同一事件。
- 实测：对已有全 247 FD2 验证数组，速度 0.10 下四阈值有效 GT 事件由审计 4/4/4/3 变为正式 helper 5/3/5/3；提前/漏接触数由 3/0/1/1 变为 2/0/2/0；后退时间 bias 从 −0.1625/−0.1750/−0.2125/−0.2333 s 变为 −0.2200/−0.2500/−0.5000/−0.2333 s。连续距离 RMSE 从 0.202380 变为 0.202690 m。
- 必要修订：固定当前 helper 为正式 C1–C4 几何口径，评价 JSON 增加完整掌/腕、躯干、聚合及事件规则元数据；本新文件记录与早期审计的差异，不覆盖早期审计或已生成候选 JSON。简报旧数字仍是早期定义下的真实结果，但不能被引用为正式 helper 的事件 baseline。
- 因为新候选和 prior 在同一 helper 中重算，候选比较仍公平；此问题不要求重训或改 loss。

### DA2-2：现行相位流没有“状态转换”模型，类型图也没有硬接触响应门

- 类型：归因/方法。
- 位置：简报“相位采用有符号左右分离及状态转换”；模型 leg_net 与 _EventGraphBlock。
- 根因：C3 当前腿流是 obs 腿位置/速度与 prior root plan 的 MLP 系数纠正器，没有静止/准备/摆动/支撑显式状态、hazard 或事件触发解码。C2 一并启用人物内骨架消息、接触邻接及 event embedding，一般跨人均值上下文保留；双向时序卷积仍可提前读取先验未来。
- 必要修订：当前方案称“专用腿纠正流 + 有符号低通相位监督”和“软类型关系图 + 时间有序累积特征”。状态转换/响应门属于 `20261014-113544-ntu2p-event-controlled-dct-diffusion-candidate-design.md` 的后续候选，不得借其机制描述当前 C1–C4。C2 对 C1 的增量只能归为图包，不能单独归为接触边的因果作用。
- 这不是已发现的训练 bug，也不要求改正在训练的模型；是必须保留的解释边界。

### DA2-3：现有 Energy Score 是逐帧逐关节边际分数，不能单独验证互动联合时序

- 类型：证据/评价。
- 位置：随机评价 ES 与简报“概率质量”泛称。
- 根因：utils.ntu2p_probabilistic_metrics.energy_score 先对每个 xyz 点计算两样本距离，再对帧/关节平均，等价于边际分数之和。它不能识别具有相同逐点边际、不同时间/人物依赖的分布。
- 解析反例：两个样本分别为整段 +1/−1，与逐帧交替翻转的两样本，对零 GT 得到完全相同 ES（当前 K=2 无偏估计皆 0）；前者帧差 0，后者帧差 2。该反例只用于展示评分的联合依赖盲区，不模拟人体。
- 必要修订：输出和报告明确标注逐点边际 ES；继续合并脚滑、jerk、固定多样本接触/相位审查。若要声称完整时序分布校准，另预登记联合轨迹/事件分布分数，本轮无需临时加入一个新 gate。改善 ES 只能限定为该分数下的概率误差改善。

## 随机评价代码的真实修复项

1. `sampling_smoke.json` 的实际 K=2、checkpoint 100 step，但没有实际窗口数或 is_smoke，mode仍写“标准随机DDIM”；这会让片段流水线结果被误认正式评价。新增实际 num_windows/K/NFE、完整窗口数、checkpoint/candidate/seed、is_smoke及其触发理由；正式预登记 scope 为 C4 seed0 EMA5000、H-val247、K10、NFE20/50、seed2718。
2. 预登记要求固定前三样本自然度/接触，当前只算每种 DDIM sample0 接触。扩展前三固定样本（包括 bootstrap）接触，不按 GT 挑样；保留原 sample0 入口并增加可查的全名字。
3. export_arrays 当前可覆盖旧文件，且未创建其父目录。与 JSON 一样在计算前拒绝已有导出文件，写入时使用排他创建，父目录正常创建；历史 smoke 和候选产物均不重写。
4. 当前 bootstrap 检查 parent manifest/hash，却可接受同协议 in-sample 或跳过 OOF 检查的库，也没有核验 K12/saturate codec。正式评价补核 `mode=oof`、smoke_skip_oof_assert=False、默认旧codec_config；把实际 bank config 指纹与模式写入结果。现有默认库已核对符合要求，不需重建。
5. 统一确定性评价输出接触几何定义元数据，方便后续 driver 或最终报告识别口径；不改变指标函数或已有结果值。

这些修复局限于独立 `eval/eval_ntu2p_graphdiff_sampling.py`、`eval/eval_ntu2p_v2.py`，不修改 model/train/helper/driver，也不改变本轮采纳阈值。

## Minor

- 简报“相同预算”应限定为相同训练步、样本和两次纠正器调用；图/腿开关有效容量与运行 FLOPs 不完全相同。C3/C4 结构相同，适合检验加噪辅助任务增量。
- cumulative memory = 1−∏(1−p) 会把持续弱接近累积成大值，例如距离0.35m、阈值0.20、温度0.05时 p≈0.0474，50帧累积≈0.912。这在 helper docstring 已披露，当前不是硬门；不能在结果里把大记忆值当作已真实接触证据。
- 来源核验是同一代理分阶段执行而非独立人员，简报已正确披露。快速十篇近邻检索只支持已知组件先例，不支持排除性“无人做过”。

## 最强反对论点

当前候选可能只是同一个冻结 DCT 先验上的增量纠正器，在额外距离/腿监督下改善数值，却仍由先验决定接触事件和起步形态；C4 的随机辅助任务可能只正则化点输出。即便跑分提高，也要分别用正式六段距离、相位/滑行、有效事件逐例和随机自然度限定实际解决了什么。

## 尚缺证据

- 新候选终点相对 C1、C2、C3 的归因，三 seed 与最终测试均未完成。
- 接触 proxy 定义改变后的逐例事件表与审查图，尤其所有阈值共同有效数据极少。
- 多样本的时序/跨人联合分布校准证据；边际 ES 不能独立提供。

## 修复验证计划

在 CPU 用已有真实 arrays 与默认 OOF bank 验证新元数据和库校验；对不存在/已有导出路径验证排他保护；用临时产物或只读历史结果核对 is_smoke；py_compile 通过后把新结果写至新时间戳文件。完整正式随机评价尚未启动，父代理将使用修复后的入口。
