## 结论

1. **采纳 rootdct**（root 轨迹锚定 DCT 头，K=5），成为新的主线。val 终点 3 seed：
   - mpjpe 0.17512 ± 0.00140 → **0.17058 ± 0.00023**（−2.6%，采纳门槛为 ≤ 0.17372）；
   - xyz_mse −8.4%，xyz_mae −2.4%；
   - gate 3/3，dct_mid 0.585（对照 0.583）；
   - seed 标准差从 0.00140 缩到 0.00023。
2. **test 复现**（只评估选中配置）：
   - mpjpe 0.18816 ± 0.00046 → **0.18455 ± 0.00011**（−1.9%）；
   - xyz_mse 0.02928 → 0.02806（−4.2%），xyz_mae 0.09049 → 0.08896（−1.7%）；
   - 相对 base −23.0%，相对 copy-last −37.7%；
   - gate 3/3，frozen 0.101（GT 0.085）。
3. **机制：整体平移与两人相对位置改善、局部姿态持平；收益在中程最大，没有降低 2.5 s 处的 root 平移误差**：
   - 改善集中在整体平移与两人相对位置：test 上 root 误差 −2.8%，两人相对 root 误差 −5.1%；局部姿态误差 +0.2%，基本持平。这符合整体平移参数化的预期。
   - 按 horizon 看，改善在第 15–40 帧（0.75–2 s）最明显，这一段占逐帧 mpjpe 累计改善的 64%（val）/ 73%（test）。例如 test 第 20 帧 root 0.108 → 0.103，相对 root 0.158 → 0.150。
   - 第 50 帧：root 平移误差回到对照水平（val 0.182 → 0.181，−0.3%；test 0.197 → 0.197，−0.2%）；但 mpjpe 仍降 1.8%（val）/ 1.1%（test），两人相对 root 仍降 2.5% / 1.5%，逐 seed 方向一致。
   - 预登记的机制核对"root 误差随 horizon 的斜率"（最小二乘，mm/帧）：
     - 第 1–50 帧 val 3.10 → 3.09、test 3.36 → 3.34，基本不变；
     - 第 30–50 帧 val 2.88 → 3.07、test 3.28 → 3.59，后段反而更陡，中程的 root 优势到第 50 帧衰减为约 0。
     - Stage 3 "root 线性增长可修"的假设没有得到支持。
   - 解读（未验证）：这与启动前分析的倾向相容，长程 root 漂移可能主要来自 10 帧观测下的内在不确定性（匀速外推在 f50 只比 copy-last 好 3%；模型 root 修正在 GT 残差方向上的回归系数为 0.49，与约解释一半方差的条件均值估计一致）。但本实验只说明这一结构改动没有降低 f50 的 root 平移误差，不能区分内在不确定性与模型或结构的限制。
   - 收益幅度：计划对本轮改进的预估是 1–3%，并把 root 头的收益定性为"保守"；实际 val mpjpe −2.6%、test −1.9%，落在预估区间的中上部。
4. **inter 权重 1 / 3 / 10 都不采纳**，L2 没有达到门槛：
   - inter10（约占总 loss 33%）L2 三项全部变差：mpjpe +3.8%，xyz_mse +8.2%，xyz_mae +4.1%；局部姿态也 +4.5%。3 个 seed 上一致改善的只有它直接优化的关键关节关系误差（−5.6%）；两人相对 root 误差均值 −1.2%，但 seed 间不一致（−0.2 / −4.4 / +0.8%）；接触误差反而 +10%。
   - inter3 / inter1 的 L2 与对照持平：mpjpe −0.5% / −0.2%，均在 1 个 seed 标准差内。
   - inter3 的关键关节关系误差在 3 个 seed 上稳定改善（−6.2 / −4.3 / −5.0%，均值 −5.2%）；两人相对 root 误差均值 −4.2%，但逐 seed 为 −5.8 / −0.6 / −6.1%，其中一个 seed 接近持平。
   - 接触误差变差：inter3 +7.3%，inter1 +10.4%。
   - 按预登记规则，关系指标不能单独支撑采纳。而且接触误差与关键关节误差方向相反，不能笼统说"交互更好"。
   - 当前 `inter_loss_weight=0.01` 在归一化下实际等于没有 inter 损失，这个结论保持不变。它现在是一个已知的空设置，不代表"交互损失有效"。
5. **Stage B 未触发**：只有 root 头被采纳，没有需要组合的 inter 权重。

## 对协议与 AGENTS.md 的影响

- **主线改为 rootdct**：s2_5 配置 + `--ema_decay 0.999` + `--root_head_mode dct --root_dct_k 5`，10000 step × 3 seed，报告 `ema/` 终点。
  - 主数字：val mpjpe 0.1706 ± 0.0002，test 0.1845 ± 0.0001。
  - 主线 checkpoint：`save/forecasting/ntu120_label/ntu2p_residual_refiner_xyz_artic_rootdct_s2_5_dct1_root01_s{0,1,2}_10000/ema/model000010000.pt`，单权重可视化用 s0。
- **`inter_loss_weight` 保持 0.01**（实际无效），不改为 1 / 3 / 10。
- **汇报边界**：
  - 可以说"显式 root 运动学输入 + 整体平移参数化带来 L2 与两人相对位置的改善，主要在 0.75–2 s"；
  - 不能说"解决了长程 root 漂移"；
  - 不能把 inter3 的关系指标改善写成交互建模收益：L2 未过门槛，且接触误差变差。
- **后续**：
  - 长程（≥1.5 s）root 与姿态的多模态交给 Track B residual diffusion，以 rootdct 终点为确定性底座；
  - 解耦变体（delta 头不能动 root）按计划只在 root 头有部分收益时考虑。本轮收益集中在中程，第 50 帧的 root 平移误差与对照基本相同（第 50 帧 mpjpe 仍有 1–2% 改善）。判断（未验证）：解耦不太可能改变长程 root 漂移，暂不做，保留为可选跟进。
