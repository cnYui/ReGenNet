总览

一次前向：观测 → 场景规范系 → DCT 频率 token → 6 层 Mixer → 三个零初始化输出头 → 残差 DCT 解码 → 加回末帧 → 骨架投影。

  1. obs + 动作
  2. 1 规范化
  3. 2 DCT token
  4. 3 Mixer ×6
  5. 4 三个输出头
  6. 5 IDCT × ramp
  7. 6 组装 + 刚体手
  8. 7 + obs_last
  9. 8 骨架投影
  10. future 50 帧

规范系

双人共享场景系（原点 = 双人 pelvis 中点，+X = A→B 水平连线），B 再转到"朝向对方系"，相对几何直接成为坐标；A6 设计里最强的归纳偏置。

残差 DCT

输出是相对观测末帧的低阶 DCT 残差。输出头零初始化、ramp 首帧为 0，初始输出逐位等于 copy-last。

刚体手 + 骨架投影

手指 = 手腕 + 手旋转作用于观测末帧偏移；末端投影固定骨长，对应 ReGenNet 的 SMPL-X 运动学表示（输出为合法骨架）。

腿部专用流

A6 诊断：腿在共享主干梯度里仅约 3%（手指约 83%），所以腿由独立流预测：输入 detach，梯度不回主干。

主线前向数据流

张量形状为实测（B 为 batch）。两个人共享全部权重，由 role embedding 区分施动 / 受动。

D3

SkeletonProjector 规则

自上而下 · 按层级批处理
对象做法
root取预测 pelvis
单子节点（脊柱链、颈、锁骨、脚掌…）子 = 父 + 骨长 · unit(预测子 − 父)：预测点到"以父为球心、骨长为半径"球面的最近点
四肢（髋-膝-踝、肩-肘-腕）解析两骨 IK：末端可达时精确保持预测位置；肘 / 膝在两球交线圆上取离预测最近点
多子节点（pelvis、spine3、head）加权 Procrustes 求全局旋转 G，子 = 父 + G · 模板偏移
手（每手 15 指节）以 obs_last 的指节相对手腕构型为刚体模板，Procrustes 对齐预测点云后整体放置

骨长与模板取自 obs_last（随样本变化，不依赖固定静息骨架）；Horn 四元数法求旋转，反向用最优性条件闭式解；float64。

D4

刚体手与坐标回转

手指（每手 15 个）Δ_j = Δ_wrist + R(ω_h)·o_j − o_j
o_j = obs_last 中 x_j − x_wrist；ω_h ∈ ℝ³ 为 local 头输出（已乘 ramp）
回转链朝向对方系 → B 的 x、z 取反（对合）→ 场景规范系 → Rᵀ → 相机系
落到相机系末帧上pred_free = obs_last + Δ_cam：只旋转残差，Δ = 0 时逐位等于 copy-last

全部 3×3 变换逐元素乘加实现，避开 Ampere 上 TF32 的 1e-4 m 级误差；ω = 0 时 Rodrigues 严格恒等。

  • + 左右踝前后分离的低通相位损失 0.1

核对与边界

怎么核对的

  • 在 CPU 上实例化真实 checkpoint save/forecasting/ntu120_label/ntu2p_v2_A6-F-A5f0.05-A4-GH0.5-FD2_s0_10000/ema/model000010000.pt：总参数 3,649,533 = checkpoint 的 num_params，各模块参数之和逐项相加相等
  • 张量形状来自前向钩子实测（B=2）；图纠正器取 C4 / F3 的 5000 step EMA checkpoint，可训练参数 496,867 与 4,146,400
  • 源码：model/forecasting_ntu2p_intermixer.py、utils/ntu2p_canonical.py、utils/ntu2p_kinematic_projection.py、utils/ntu2p_gait_losses.py、model/forecasting_ntu2p_graphdiff.py、utils/ntu2p_contact_graph.py、utils/ntu2p_residual_codec.py、train/train_ntu2p_v2.py

解释边界

  • 当前主线是确定性回归（DCT-Mixer + 骨架投影），不是扩散模型；扩散路线在本任务上没有带来提升
  • person_mix 与相对几何给了跨人信息，但没有"屏蔽对方观测"的同架构消融，L2 提升不能归因于交互建模
  • test mpjpe 0.1805 ± 0.0005 是 3 个 seed 的均值 ± 样本标准差；选型只用受试者留出 val，test 只评估一次
  • 结果来源：20260926-005610-ntu2p-v2-final-result.md、20260926-165932-ntu2p-finger-dedup-result.md
