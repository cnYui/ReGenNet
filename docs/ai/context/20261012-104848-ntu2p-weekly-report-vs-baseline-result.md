# NTU 双人动作预测周报（截至 2026-10-12）：相对初始 baseline 的全方位提升

## 一句话结论

在同一批 **1253 条 test（受试者与训练集不重叠）** 上，最新主线（`A6-F-A5f0.05-A4-GH0.5-FD2`，3 seed）相对最初做的独立单人 baseline：

- **mpjpe 0.2397 → 0.1805（−24.7%）**，xyz_mse −40.5%，xyz_mae −22.8%；相对 `copy-last` 分别是 −39.0% / −59.8% / −36.2%。
- 配对 bootstrap 的 mpjpe 相对变化 **95% CI 为 [−26.2%, −22.9%]**，79.6% 的样本更好；3 个 seed 各自相对 baseline 为 −24.6% / −24.9% / −24.6%。
- 更重要的是**质变，不只是数字**：baseline 的输出是"整体平移、四肢几乎不动"（步态频段能量只有 GT 的 0.2%，预测步数 0.03；人物在移动的帧里 59% 是脚与骨盆锁定一起滑行）；最新主线恢复到步态频段能量 GT 的 60%、步数 1.46（GT 2.19）、滑行帧比降到 0.203，且骨长误差严格为 0。
- **仍然没有改善的地方**也写在第 5 节：0.25 s 以内无增益（root 误差 +4.5%）、速度/加速度误差略升、步频仍偏慢、少数小样本动作变差；并且这个提升**不能归因于"交互建模"**（见第 5 节）。

> 本周没有新增训练：最近一次模型改动是 2026-09-26（FD2 + Track B）。本周的工作是把截至目前的各代主线，用同一个评估脚本在同一批 test 样本上与初始 baseline 做**统一口径复评**，并汇总成本报告。

## 3. 提升从哪里来（按里程碑的边际变化）

| 里程碑 | 做了什么 | mpjpe | 较上一级 | 占总降幅 |
|---|---|---:|---:|---:|
| 独立单人 baseline | 每人只看自己，共享参数 | 0.2397 | — | — |
| 首版 residual refiner | 冻结 baseline，加人物内 temporal self-attention + 双向 cross-person attention + 零初始化残差头 | 0.2268 | −5.4% | 21.8% |
| + 摆动恢复 | 针对"回归到均值、肢体不动"：损失尺度归一化、局部速度损失、分频带 DCT 幅度损失、root 权重 0.1、饱和 ramp | 0.1967 | −13.3% | 50.9% |
| + 权重 EMA | `--ema_decay 0.999`，报告 EMA 终点；终点抖动 −87% | 0.1882 | −4.3% | 14.4% |
| + root DCT 头 | root 轨迹用低阶 DCT 参数化，改善整体平移与两人相对位置 | 0.1845 | −1.9% | 6.1% |
| v2 InterMixer（GH） | 端到端场景规范系双人 DCT-Mixer 取代"冻结 base + refiner"；可微骨架投影（骨长恒定）、脚接触损失、腿部专用流；参数 5.6M+7.1M → 3.65M | 0.1810 | −1.9% | 6.0% |
| v2 + FD2 | 主损失只用身体 + 每手 2 个关节（刚体手下 30 个手指关节原占 loss 81%） | 0.1805 | −0.3% | 0.8% |

- **最大的一块提升（约一半）来自"摆动恢复"**：首版 refiner 虽然 L2 下降，但摆动指标与 baseline 几乎一样（1.2–2 Hz 能量仍只有 GT 的 0.2%，没有通过摆动 gate）；诊断结论是确定性 L2 回归对多模态未来回归到均值，加上零初始化 future 头造成的鞍点，改损失后才真正"动起来"。
- v2 与 FD2 的 L2 增益不大（合计 −2.2%），但**自然度收益更大**（骨长、迈步相位、滑行，见 4.4）。
- 这是**按顺序的边际变化，不是严格因果消融**：各级同时改变了结构/损失/训练步数（首版 5000 step，其后 10000 step）。

## 5. 没有改善、需要如实说明的地方

1. **极短时程没有收益**：0.25 s 时整体 mpjpe 仅 −4.0%，root 误差 0.0331 → 0.0346（+4.5%）；收益从 0.5 s（−18.6%）以后才显现。
2. **速度/加速度误差略升**：速度误差 +3.1%，加速度误差 +1.9%。模型现在会输出真实的肢体摆动，而 GT 帧间还含拟合抖动，摆动相位对不上时逐帧速度误差不降反升；它们不是视觉质量的好坏指标，但需要如实报告。
3. **脚悬空帧比略升**：0.091 → 0.108（GT 0.066）。
4. **步频仍偏慢、幅度偏小**：步数 1.46（GT 2.19），腿摆幅为 GT 的 56%，相位相关 0.40–0.48；出拳等动作幅度偏小。局部姿态误差在 >1.5 s 后降幅回落到 13%，属于确定性回归对多模态未来的"均值化"，不能靠加大长程权重修复（已验证）。
5. **滑行帧比 0.203，仍是 GT（0.030）的近 7 倍**。
6. **少数动作变差**（4 类，每类 n ≤ 6），见 4.5。
7. **提升不能归因于"交互建模"**：
   - 相对 baseline 的 −24.7% 是**联合双人输入 + 架构 + 损失 + EMA + 骨架投影**的总和，没有做"同架构屏蔽对方观测"的消融；
   - `inter_loss_weight=0.01` 在尺度归一化下实际等于没有 inter 损失项；
   - 4.2 的双人关系指标降幅与 root 误差同步，不是独立证据；
   - 目前只有"联合 direct xyz 略优于独立单人（test 0.2387 vs 0.2442）"这一条同口径证据说明联合输入有一定价值。
8. **baseline 只有单 seed**，两次重训相差约 1.8%（0.2442 / 0.2397），已在 1 节脚注说明。
9. 本报告所有 L2 提升均为**确定性点预测**口径，不代表对多模态未来的概率质量。

## 6. 探索中被否定的路线（不属于提升，但属于本阶段结论）

| 路线 | 同口径结果 | 结论 |
|---|---|---|
| 联合 direct joint xyz Transformer | test mpjpe 0.2387（独立单人原 run 0.2442） | 略优于独立单人，说明联合输入有一定价值 |
| ReGenNet 风格 rot6d diffusion，`L_dm`-only | val 最佳 mpjpe 0.3395（val copy-last 0.2779） | 未过 gate |
| 同上，`L_dm + L_inter` | val 最佳 0.4937；test 0.5307（test copy-last 0.2960） | 三项均未超过 copy-last |
| 显式跨人 attention diffusion | val 最佳 0.5507 | 未超过 copy-last |
| Track B 残差扩散（ResDiff-OOF+） | 单步条件均值 L2 −2%，但概率质量不如直接抽取真实残差的 bootstrap；单样本 jerk、穿地、自身脚滑变差，审查图有起步突跳与弓步 | 按预登记规则**不采纳** |

**需要明确**：当前最佳模型是**确定性回归**（DCT-Mixer + 骨架投影），**不是扩散模型**。ReGenNet 在 SMPL-X 运动学表示上"输出合法人体"的优点，由可微骨架投影吸收；扩散本体在本任务上没有带来提升。

## 7. 下周建议（提议，未执行）

1. **做交互贡献消融**：同架构下屏蔽/打乱对方观测、或训练"人物隔离版"，量化"联合"本身贡献了多少；这是回答"提升来自哪里"的缺口。
2. **改报合理性/多样性指标**：局部姿态在 >1.5 s 饱和、步频偏慢都是多模态问题，建议对 ≥1.5 s 的预测改报步数分布、先迈脚、相位等合理性指标，而不是继续压 L2。
3. **小样本动作分层报告**：n ≤ 8 的类别单独列出、不进入结论；必要时按 NTU60/NTU120 来源分报。
4. **检查极短时程（<0.25 s）**：确认 root 误差 +4.5% 是否来自首段输出头，而不是随机波动。
