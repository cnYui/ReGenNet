## 方案回顾

- **底座**：冻结的 v2 + FD2 主线，使用受试者留出协议下的权重（`save/forecasting/ntu120_label/ntu2p_v2subj_A6-F-A5f0.05-A4-GH0.5-FD2_s{0,1,2}_10000`）。
- **生成对象**：GT 相对 v2 的残差，在个人朝向系中取斜坡 DCT 前 12 阶，覆盖 root 与 21 个身体关节。
- **模型**：ReGenNet 式余弦扩散，x0 预测。去噪网络 4.95M 参数，两人全部 token 联合注意，输出层零初始化（初始输出即 v2）。
- **训练目标**：按受试者 3 折交叉拟合得到的 OOF 残差，避免学到底座在训练集上偏小的残差。另跑了 in-sample 对照臂。
- **采样与模式**：NFE50；概率模式 F 用 τ=1，展示模式 R 用 τ=0.8。
- **步数与时间**：main 臂 3 seed × 20000 step。2026-09-26 17:55–19:20 在 cuda:0 上完成，包括 3 个折模型、残差库、生成器、评估与审查。

## 解读

1. **没有学到比"抽真实残差"更好的条件分布**。
   - 生成器在步态统计上确有帮助：步数分布、先迈哪只脚的概率都明显优于确定性 v2。
   - 但整体概率质量不如 bootstrap，单样本的物理合理性（jerk、穿地、自身脚滑）也变差。
   - 数据只有约 1700 条序列、3 万个窗口，比较可能的原因是：学习型条件生成器的样本效率还不如非参数重采样。
2. **单步条件均值的 −2% L2 不能当作确定性改进**。
   - 它本质上是一种均值估计。同一份评估中，3 seed 集成均值 mpjpe 为 0.1665（−3.3%），但 dct_mid 从 0.63 掉到 0.24，正是已知的"平均会压掉摆动"。
   - 单步均值的摆动与自然度没有评估，是否可用需要先验证；若要利用，只应作用在 root 或低频通道上。
3. **确定性主线（v2 + FD2）保持不变**。Track B 不进入原协议复训，也不评估 test。

## 后续候选（未实现）

- **非参数残差 bootstrap 作为随机模式**：它的 ES 已优于学习型生成器。需要专门评估单样本的物理合理性，也就是把残差叠加到 v2 后的起步突跳和穿地问题。
- **抑制起步突跳**：给残差加 ramp，或加首几帧速度一致性约束，然后重评 E5。
- **只在 root / 低频上使用条件均值或集成**：检验能否拿到 L2 收益、同时不损失摆动。
