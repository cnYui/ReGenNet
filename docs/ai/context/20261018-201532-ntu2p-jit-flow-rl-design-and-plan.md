# NTU2P JiT 流匹配 + 双人接触图 + GRPO（JiT-RL）：设计、预登记与计划

## 1. 用户需求与范围

用户（2026-10-18）要求：

1. 把扩散模块融进当前双人动作生成（v2+FD2，纯 DCT 确定性回归），并结合 DCT，设计新方法，相对纯 DCT 基准提分；可并行多跑几种架构。
2. 处理"A 伸手碰 B 肩膀，手还没碰到 B 就开始躲"的问题，用两人关节之间的图结构约束让动作更自然。
3. 腿部已无问题（单独一条腿流、能左右迈步），保留。
4. 使用 JiTRL。仓库与公开检索均没有名为 JiTRL 的工作；已向用户确认其含义为 **JiT（Li & He, "Back to Basics: Let Denoising Generative Models Denoise", CVPR 2026，arXiv 2511.13720）的 x 预测流匹配 + RL（GRPO 类奖励微调）**。

本轮按仓库协议执行：受试者留出 H-val 选型，test 只在采纳后评估一次；所有训练显式 `cuda:0`；新增文档只建时间戳文件。

## 2. 与上一轮的关系、本轮新诊断

上一轮（`20261014-153106-ntu2p-contact-graph-diffusion-final-result.md`）在冻结/解冻 FD2 上加时间纠正器、显式掌腕—躯干图、腿 DCT 头与 ReGenNet 余弦扩散辅助，7 个候选均未采纳：冻结纠正 mpjpe 只降 0.57–0.61%，端到端退化 2.2%，扩散/图无增量；C4 随机 DDIM 单样本 mpjpe .2113、jerk 与穿地明显变差。约束："不能重复包装硬门或调宽采纳线"；"DCT+图+扩散已有近邻，不能声称首创"。

**新诊断 1（DCT 截断不是提前躲的原因）**。`scripts/diag_ntu2p_dct_onset.py` 把 GT 未来投影到 InterMixer 的同一输出基（toward_other 系残差，root 8 阶、局部 20 阶 DCT，×saturate ramp，最小二乘），再按上一轮事件规则（0.20 m、3 帧持续、退后速度 0.10/0.20 m/s）测后退起点：

| 数据 | 有效接触→后退事件 | 投影后后退起点偏移 | 投影后接触起点偏移 | 投影 oracle mpjpe |
|---|---:|---:|---:|---:|
| train 推人重叠窗（914） | 369 / 262 | −0.008 s / −0.008 s | +0.012 s / +0.019 s | 0.0163 |
| val 推人重叠窗（82） | 30 / 19 | −0.100 s / −0.005 s | +0.010 s / +0.003 s | 0.0149 |

FD2 在同类子集上后退平均提前 0.16–0.23 s（`20261014-111541-ntu2p-contact-gait-data-audit.md`），远大于表示本身带来的 ≈0.01 s。**DCT 表示保留**；提前躲来自预测器。

**机理假设 2（需本轮检验）**：确定性 L2 回归在接触时刻不确定时，输出是"不同接触/后退时刻的轨迹"的平均；一族起点随机的后退曲线取均值，就是一条更早开始、更缓的后退——正是"手没到就躲"。数据审计里 FD2 的"后退−接触"间隔被压缩（GT 7/6/9 帧 → FD2 0/2/7 帧）与此一致。生成模型的**每个样本**内 A 的到达与 B 的反应联合采样，时序可以自洽；逐帧中位数（而非均值）聚合也会给出"多数样本已后退才后退"的陡峭起点。这是本轮把扩散引入的核心理由，而不是"扩散更新"。

**风险**：L2 分数在条件均值处最优，单个样本的 L2 必然更差（差值是条件方差）。因此本轮把"打分读出"和"自然样本读出"分开预登记，不拿单样本 L2 冒充点预测进步，也不拿点预测 L2 证明随机样本质量。

## 3. 方法

### 3.1 状态表示（全部候选共用）

- 坐标：沿用 InterMixer 的场景规范系 + "朝向对方"人物系（`canonical_ab_fallback=camera_x`）。
- 流的状态 `x`：未来 50 帧相对观测末帧残差在 ramp-DCT 基上的系数。root（pelvis）8 阶 ×3；局部（关节−pelvis）20 阶 × 28 关节 ×3，28 关节 = 身体 1–24 + 每手 index1/pinky1（25、31、40、46，正是 FD2 主损失的 hand2 子集）。每人 24+840 维，两人共 1728 维。
- GT 系数由最小二乘拟合得到（与诊断同一基）；按 train 统计的 root/局部两组标量标准差归一化，保留频谱自然衰减（像图像按全局而非逐频率归一化）。
- 解码：IDCT × ramp（首帧残差严格 0）→ 加回观测末帧 → 其余 26 个手指按观测末帧相对手腕的模板平移 → `SkeletonProjector`（骨长恒定、刚体手；手部 Procrustes 只给 index1/pinky1 权重，即由这两个指根与手腕决定手部旋转）。与 FD2 的骨长 0 误差保证相同。

### 3.2 JiT 流匹配（x 预测 + v-loss）

按 JiT 原文：`z_t = t·x + (1−t)·ε`（t=1 为干净数据），网络直接输出 `x̂`，`v̂ = (x̂ − z_t)/(1−t)`，损失 `‖v̂ − (x − ε)‖²`，分母下限 0.05；`logit(t) ~ N(−0.8, 0.8²)`；采样用线性 t 网格 Heun ODE（默认 NFE 20，报告 50 作敏感性）。x 预测在高维、低维流形数据上比 ε/v 预测稳（JiT 的论点），对 1728 维系数直接适用。

每个训练 step 两次前向：

1. **确定性端点**：t=0、`z=0`，解码后施加 FD2 的完整损失配方（s2_5 主损失 hand2 子集、脚接触 0.05、骨架投影辅助、腿步态 0.5、dct_mid 排除腿），即与 FD2 同一目标；这是可部署的点预测读出，不伪装成随机样本。
2. **随机 t 去噪**：JiT v-loss，权重 λ_flow=1（不调）。

### 3.3 去噪器族（并行筛选的多种架构）

所有候选共享 3.1/3.2、腿流、读出与损失；腿部统一由**条件化腿流**（FD2 的 `NTU2PLegStream` 在个人朝向系中工作，新增噪声腿系数与 t 条件输入，读 detach 的 root 预测）输出腿关节系数，保留"腿单独一条流"。

| 代号 | 去噪器 | 自条件 | 两人接触图 | 时间因果 |
|---|---|---|---|---|
| J1 | **MixerFlow**：FD2 的 DCT-Mixer 主干（系数轴时间混合 / FiLM 通道 MLP / 人物混合），噪声系数作为同频 token 的输入通道，t 进 FiLM | 否 | 否 | 否 |
| J2 | J1 + 自条件 + **动态接触图通道**：由上一轮 x̂ 解码出的双向手—躯干距离、接近速度与因果接触记忆（时间曲线）取窗口 DCT 后注入 token | 是 | 关系通道 | 否 |
| J3 | **STG-Flow**：JiT 式 Transformer（adaLN-Zero、qk-norm、RMSNorm、SwiGLU、瓶颈 patch 嵌入），token = 人物 × 身体部位（躯干/左臂/右臂/左腿/右腿）× 5 帧时间块（含 2 个观测块）；部位间可学习骨架偏置；输出时域残差再最小二乘投回 DCT 系数 | 是 | 否 | 否 |
| J4 | J3 + **接触图注意力偏置**（对方手臂块 ↔ 本人躯干块，按自条件估计的逐块手—躯干距离与接近速度，零初始化的可学习偏置）+ **跨人时间因果掩码**（本人第 i 块只能看对方第 ≤i 块） | 是 | 注意力偏置 | 跨人因果 |

J2/J4 的接触图只读模型自己的当前估计与观测，不读 GT。J4 的跨人掩码使"B 在第 i 块的去噪输出"不直接看到 A 在 i 之后的状态；同一人内部仍双向，且输出投回低阶 DCT 会有平滑，因此只是结构偏置，不声称严格因果保证。

### 3.4 读出（预登记的候选集合，按 val 选择）

- `endpoint`：确定性端点（单次前向）。
- `sample`：固定种子单样本（自然度、交互时序读出）。
- `mean16` / `median16` / `medoid16`：16 个 ODE 样本的逐关节均值、逐关节几何中位数（Weiszfeld 10 次迭代）与 medoid（与其余样本平均 mpjpe 最小的那条真实样本）；前两者再经骨架投影恢复骨长。几何中位数是 mpjpe 的贝叶斯最优点（均值对应 mse），medoid 是可直接观看的一致样本。

### 3.5 JiT-RL：GRPO 奖励微调

策略为随机 flow-DDIM：`z_s = s·x̂ + (1−s)·(√(1−ρ²)·ε̂ + ρ·ξ)`，`ε̂ = (z_t − t·x̂)/(1−t)`，每步高斯、对数似然闭式；训练用 10 步（Flow-GRPO 的去噪步数缩减），评价仍用 ODE。每个条件采 G=16 个样本，组内标准化优势，PPO-clip ε=0.2、每批 2 次内更新，对冻结参考策略的逐步高斯 KL（β=0.04，Flow-GRPO 默认量级），同时保留端点配方损失（权重 1）防止确定性读出漂移；EMA 0.999。

奖励只用于训练（GT 来自 train），每项按 copy-last 量级归一化：

- `acc`：−mpjpe（身体 25 + 4 指根，同 FD2 主损失子集）；
- `rel`：−双向手—躯干距离曲线 RMSE（相对 GT）；
- `ant`：−Σ_受动者 relu(A_样本 − A_GT)，只在 GT 有新接触的受动者上计（定义见 4.2）；不要求比真实人类更"迟钝"，GT 没有接触时允许离开；
- `phys`：−（穿地深度与 jerk 超出 GT 的部分）；不用自身脚滑：GT 的自洽脚滑反而高于模型（`self_skate_loss` 注释）。

两个变体：**RL-A**（只 acc）与 **RL-F**（acc + 0.5 rel + 0.5 ant + 0.25 phys）。RL 只在第 1 阶段最好的一个流模型上做（若两个架构在不同目标上各有优势，各做一个）。

## 4. 评价

### 4.1 打分与自然度

复用 `eval/eval_ntu2p_v2.py`（val 247 中心窗）：paired `xyz_mse/xyz_mae/mpjpe`、摆动 gate、自然度（滑行、步数、相位、穿地、jerk、骨长）、接触指标（`utils/ntu2p_contact_graph.contact_metrics`）。样本类读出另报：16 样本的单样本平均 L2、Energy Score、minADE 与样本自然度。

### 4.2 新交互时序指标（全动作，GT 不参与预测）

实现 `utils/ntu2p_interaction_timing.py`。对每个窗口、每个受动者 p（施动者 q 为另一人）：d(t) = q 双手到 p 六段躯干的最小中心距（5 点平滑，obs+future 60 帧）；obs 末 3 帧 d>阈值为"未接触起始"；未来首次连续 3 帧 d≤阈值于 τ 为新接触；退离轴 u = obs 末帧 q→p pelvis 水平方向；超额后退 e(t) = p 的 pelvis 沿 u 的位移 − obs 末 5 帧速度外推。

- **接触前后退量** A = max(0, max_{t≤τ_eff−3} e(t))，τ_eff 为**该轨迹自己的**接触时刻，始终未接触时取整段未来。
- 在"GT 有新接触"的受动者上配对：**excess_antic** = mean relu(A_方法 − A_GT)（米）、漏接触数（GT 有新接触而方法没有）、漏接触时的后退量。
- 主指标 **primary_excess_antic** = 全动作在阈值 0.20/0.25/0.30 m 上 excess_antic 的平均；另报击打类（动作 0/1/2/11/13）与推人子集。

为什么这样定义（定义前只看了 FD2/v2/A0 与 GT，未见任何新候选）：最初按"只统计有新接触的轨迹"计算，FD2 的接触前后退并不多于 GT（全动作配对 ΔA −0.012 m）；改为"始终没碰到也算"后问题显形——val 推人 0.25 m 阈值下 GT 有 6 个新接触，FD2 漏了 3 个、漏接触时 B 仍后退 0.50 m，excess_antic 0.221 m（v2 0.065、A0 0.271）；击打类 FD2 0.127 m。即用户看到的现象主要是 **"A 的手始终没真正到达、B 照样按动作标签后退"**，与确定性回归把手臂伸展幅度和接触时刻取平均一致。FD2 参照值：primary_excess_antic **0.0277 m**（v2 0.0320、A0 0.0345）。

推人子集的上一轮事件指标（后退时刻偏差、提前/缺失数、推人距离 RMSE）照报，但 val 推人只有 12 窗、有效事件 3–6 个，只作描述。

### 4.3 预登记采纳规则（只看 H-val）

参照：同 seed 的 FD2 H-val EMA 10000 终点（与上一轮相同，对 5000-step 候选偏保守）；另训 FD2 5000-step 同预算对照仅作归因。

**提分采纳**（某候选的某个打分读出 ∈ {endpoint, mean16, median16, medoid16}）：三项 L2 均 ≤ 参照 1.005×，且 mpjpe 改善 ≥ 0.8%；护栏：骨长相对误差 ≤ 1e-5、首帧 ≤ 1e-6、jerk ≤ 1.2×、穿地 ≤ 参照 +0.01、dct_high ≤ max(1.2×参照, 0.05)、摆动 gate 通过、f01–10 步态相位相关 ≥ 参照 −0.05。

**交互采纳**（`sample` 按 16 个样本平均，或某个打分读出）：primary_excess_antic 相对参照（0.0277 m）降低 ≥ 30%，且全动作漏接触总数（三阈值合计）不多于参照；同时全动作手—躯干距离曲线 RMSE ≤ 参照 1.05×，护栏同上（样本读出的 jerk/穿地以参照的 1.5×/+0.03 为限，并单列报告）。

只满足一项时只声称该项；两项都不满足则按负结果停止，不延长训练、不调宽门限。图/因果的贡献按 J2 vs J1、J4 vs J3 同口径判断，无增量就如实写"无证据"。RL 的贡献按 RL-F vs RL-A vs 未 RL 同口径判断。

采纳后：10000 step × 3 seed（H-val）复现，均值仍过线才进入原协议 train 1758 × 3 seed 复训与一次 test。

## 5. 实验矩阵与预算

单张 RTX 3080 10GB（与其它会话共享，启动前查外部 GPU 进程），最多两组并发。

1. 第 1 阶段：FD2-5000 对照 + J1–J4，seed0 × 5000 step，batch 8，lr 3e-4，EMA 0.999，终点权重；每组预计 30–60 min。
2. 第 2 阶段：在第 1 阶段最好的流模型 EMA 终点上做 RL-A / RL-F，各 1500 次更新（约 1 h 内，按冒烟实测登记）。
3. 第 3 阶段（仅在采纳时）：10000 × 3 seed，原协议复训与 test。

## 6. 实施与验证

新文件：`model/forecasting_ntu2p_jitflow.py`（表示、解码、J1–J4、腿流、采样与读出）、`utils/ntu2p_interaction_timing.py`（4.2 指标与 RL 奖励的 ant 项）、`train/train_ntu2p_jitflow.py`（复用 v2 训练入口的损失、尺度、EMA、数据管线）、`train/train_ntu2p_jitflow_grpo.py`、`eval/eval_ntu2p_jitflow_samples.py`、`scripts/run_ntu2p_jitflow.py`、`scripts/check_ntu2p_jitflow.py`。`eval/eval_ntu2p_v2.py` 与 `model/forecasting_ntu2p_v2.py` 只加分派与读出参数，旧模型行为不变。

结构检查：GT 系数编解码误差等于诊断 oracle；零初始化输出等于 copy-last；首帧误差 0；骨长误差 ≤1e-5；J4 跨人因果掩码下改动对方未来块不影响本人更早块的注意力输出（在投回 DCT 之前检查）；梯度有限；checkpoint 重载逐位一致；CUDA 不可用时训练拒绝运行；GRPO 的对数似然与闭式 KL 数值核对。

## 7. 不承诺与解释边界

- DCT + 扩散（HumanMAC 等）、接触图、RL 微调扩散（Flow-GRPO、ReinDiffuse 等）都有近邻，不声称首创。
- 骨架中心距是接触代理，没有触觉/外力数据；时序改善只能表述为"接触代理下的提前后退减少"。
- 若 L2 只在聚合读出上改善，结论写成"多样本聚合读出提分"，不写成单样本或确定性模型提分。
