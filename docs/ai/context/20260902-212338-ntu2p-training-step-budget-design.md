# NTU2P residual refiner 训练步数预算设计

依据：`docs/ai/context/20260902-205844-ntu2p-articulation-recovery-stage3-result.md` 中 s2_5 配置 seed 0 的 20000 step 长训（每 1000 step 评估 val 198 条）。

## 数据

| step | val mpjpe | 说明 |
|---:|---:|---|
| 5000 | 0.1901 | Stage 2 口径 |
| 6000 | 0.1818 | 首次进入平台带（平台均值 + 1σ 以内） |
| 8000 | **0.1780** | 全程最优 |
| 10000 | 0.1849 | 平台内偏高的一个点 |
| 15000 | 0.1850 | |
| 20000 | 0.1789 | 终点 |

- 8000–20000 的 13 个 checkpoint：mpjpe 均值 **0.1823，标准差 0.0023**，无单调趋势，只有噪声与极缓慢下漂。
- 训练 loss（2000 step 窗口均值）持续下降：5k 3.18 → 8k 3.07 → 10k 2.69 → 15k 2.58 → 20k 2.23，而 val 已平——train/val gap 在扩大，是数据上限（1758 条序列、类别严重不均衡）的表现，不是步数不足。
- frozen 比例随长训从 0.09 缓升到 0.12（GT 0.098），高频带 0.007 → 0.010：长训有轻微趋向保守的副作用。
- 5000 → 8000 贡献了几乎全部增益（−6.4%）；8000 → 20000 多花 2.5 倍时间换来的差异（0.1780 → 0.1789）在噪声内。
- 对比：旧配置（Stage 1 `s1_2_long20k`）20000 step 全程平直，说明"多训是否有用"取决于目标函数是否已经把模型推出鞍点，而非步数本身。
- 3 seed @5000 的逐 checkpoint 轨迹显示配置之间的**排序**从 3000 step 起已经稳定。

## 结论：两档预算

| 用途 | step | 理由 |
|---|---:|---|
| 消融 / 配置筛选 | **5000**（≈14 min） | 排序自 3000 起稳定；5000 是 Stage 1/2 的既有口径，保持可比 |
| 最终数字 / 汇报 | **10000**（≈28 min） | 膝点在 6000–8000，加 25–60% 余量覆盖 seed 差异；再往后只有噪声，且 train/val gap 与 frozen 同时恶化 |

不建议继续用 20000：时间翻倍、收益在噪声内、副作用方向不利。

## 配套约定

1. **checkpoint 选择取终点，不在 val 上挑最好**：平台内 ±0.0023 的差异是噪声，挑最好会引入乐观偏差。最终数字报 **3 seed 终点的均值 ± 标准差**。
2. **降低终点抖动（可选、低成本）**：当前学习率恒定 3e-4 无衰减，checkpoint 间 ±0.002 的抖动一部分来自此。两种任选其一，需先在训练脚本实现并做 weight=0/关闭时的等价性测试：
   - 余弦衰减至 3e-5（最后 20% 步数），或
   - 权重 EMA（decay 0.999）用于评估。
   实现前不改变现有 run 的可比性。
3. `save_interval=1000`、每个 checkpoint 评估 val 的做法保留，用于画收敛曲线和检查 gate 是否在全程稳定通过。
4. 若后续引入更强正则、数据增强或更多数据，膝点会右移，需要用同样方法（单 seed 长训 + 平台统计）重新标定预算，不沿用 10000。

## 立即适用的下一次训练

- s2_5 配置 3 seed × **10000 step**（约 1.5 h），作为 presentation 的主线数字；
- 任何新的结构/损失改动（如 root 轨迹 DCT 头、inter 权重重测）先用 5000 step 筛选，胜出者再补 10000 × 3 seed。
