# 接触图、双腿与 DCT 扩散：本轮完整实验结果

## 决定与目标状态

本轮已完成文献核验、数据审计、模型实现、七个候选的 CUDA5000-step 筛选、C4 随机采样与最小事件控制器诊断。**七个候选均未通过预登记采纳标准，主线继续保留 v2+FD2。** 没有得到可推荐替换主线的新架构，也不能声称“规律迈步”和“先接触再后退”已解决。

筛选失败按设计停止该路线，不进入10000-step三seed复现、原协议复训或test。本轮未使用test选型；既有主线test mpjpe仍为0.1805±0.0005，它与下表H-val数字属于不同划分，不能直接比较。

实现保留为研究入口：原DCT底座、残差DCT与逆变换、掌腕—躯干显式图、双腿专用头、ReGenNet余弦扩散与DDIM均已接通。研究开关可复用，但当前证据不支持把组合本身称为首创或性能进步。

## 协议与实现

H-val为受试者留出train1709/val247，obs10/future50。同seed原FD2 EMA10000终点为参照；所有新候选seed0×5000、EMA.999终点，batch8，新纠正器lr3e-4，同主损失/接触/左右分离监督、同数据及随机流、两次纠正器forward/step。F候选额外解冻原InterMixer，lr3e-5，并完整另存冻结原FD2 reference，不能把微调底座冒充参照。所有正式训练显式cuda:0。

C1是时间纠正器，C2增加骨架与跨人掌腕—躯干图，C3再增加腿专用DCT头，C4再增加q_sample去噪。F1是端到端时间纠正器，F2是端到端图+腿流，F3再增加去噪。新纠正器496867参数，F总可训练参数4146400。图是信息交换，腿头是专用MLP，不是接触硬状态机或步态相位振子。

新残差采用16阶DCT与8帧smoothstep基，原底座DCT保留；解码复用SkeletonProjector与刚体手。点预测是明确训练的t999/xT0端点，不能作为标准高斯随机扩散样本报告。

## 接触时序与视觉证据

正式几何采用min(腕、index1/pinky1中点)到六条对方躯干段的距离。它是骨架中心距离代理；早期五段审计的有效事件数与正式评价不同，须按 `20261014-115547-ntu2p-graphdiff-evaluation-review-fixes-result.md` 区分。

val推人仅12窗；距离阈值.15/.20/.25/.30m、速度.10m/s的GT有效事件为5/3/5/3。F3在.20的3窗子集上，后退时间平均仍比GT早.20秒（FD2早.25秒）；在.15仍有1个漏接触且后退、.25仍有1个早退或漏接触、另有1个漏后退。不能凭某阈值下的零计数宣称强因果保证。

全部12推人曲线已逐图检查，F1/F2/F3基本重合；020、028、123仍有B root速度提前抬升。预固定18例加GT随机6起步去重后23例均已生成，F3三张总览覆盖全部案例，另详细检查002/020/129，先前F1/F2详细检查002/009/111/129。002、020的GT被推者后段明显换步，预测仍以脚位连续漂移为主；129已行走的左右相位基本保持。没有从结果中挑改善最大的案例。

F1/F2与F3完整审查图保存在下方结果目录的`review_f1f2/`、`review_f3/`；F3固定002/111/129视频保存在`review_f3_videos/`，仅供诊断，不推荐当作成功案例。

## 对后续架构的约束

DCT的年代不是目前失败证据，DCT+扩散与接触图均已有近邻工作；10篇2023–2026原文核验见 `20261014-113727-ntu2p-contact-graph-phase-diffusion-research-brief.md`。本轮不能承诺“别人没做过”。

现有信息交换图与软距离监督不足以保证先触后退；要进一步研究必须把手部到达、接触诱发运动、自主运动和root/站立脚约束共同设计。已有硬门负结果说明仅锁root会损坏轨迹，不能重复包装。0.5秒静止观测对起步时刻和第一脚存在不确定性，确定性位置评分也不能独立判断自然度。下一轮若启动完整事件/脚状态架构，需要新的设计、训练样本标签可靠性验证和公平对照；本轮没有擅自延长失败候选或调宽采纳线。
