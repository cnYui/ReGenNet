# NTU2P 接触图、步态与频域扩散：设计和实施计划

研究范围：`docs/ai/context/20261014-110806-ntu2p-contact-graph-diffusion-research-scope.md`。实现前创建本文件。用户已授权自主研究、架构改造与多候选实验，无需重复设计确认。

## 必须解决的问题

当前 v2+FD2 已保证骨长与首帧连续性，但起步/被推者仍滑行；旧 Track B 给全身残差加扩散后起步突跳、自身脚滑和高频 jerk 恶化。本轮先引入可验证的手—躯干事件图与双腿相位表示，再检验扩散是否带来额外收益。

DCT 是表示工具，保留它不妨碍新架构；HumanMAC（ICCV 2023）已有 DCT+diffusion，不能将组合本身称为首创。创新候选是“逐帧接触边与累积事件记忆 → 频域平滑纠正 → 共享物理约束的扩散去噪”，最后以经核验的近邻比较限定新颖性。

## 模型设计

采用组合：冻结同 seed、同协议的 v2+FD2 作为预测先验，新模块直接读 obs10、动作、先验 future50 与噪声残差。不会改写旧 checkpoint 的结构。

1. **表示和连续性**：复用个人朝向系与 body22 残差通道（root 3 + 21 个 root-relative 关节 63）。保留 16 阶 DCT，先验仍保留原 20 阶输出。新残差基采用 8 帧 smoothstep 起步包络（首帧残差=0、起始导数=0），编码用最小二乘逆，解码后复用刚体随动与 SkeletonProjector。频率截断、包络与投影共同控制突跳和高频抖动。
2. **逐帧图去噪器**：44 个 body22 节点，位置/速度、观测历史编码、角色/关节/动作和扩散时间作输入。共享消息函数，关系分为人物内骨架边、自由跨人上下文与手—对方躯干接触边。接触边由先验的掌/腕到对方身体线段的距离计算，附加接近速度、逐帧软接触与只累计过去帧的事件记忆。时序模块与图消息交替。接触信号仅来自 obs 与预测，GT 只用于训练监督和评价。
3. **双腿相位流**：在个人朝向系预测左右踝前后分离与低通速度，左右腿通过共享权重和双侧消息耦合；以先验 root 运动为条件，并增加相位敏感纠正头。训练沿用既有腿位置/低通速度、脚接触监督，增加低通左右分离监督，禁止用固定“永远左右交替”的规则处理静止、踢或垫步动作。
4. **接触监督**：可微手—身体距离一致性与接近时序损失，推人类另报告接触/后退事件误差。不把所有动作硬锁为接触后才动；接触诱发的反应与自主运动必须可分。骨架距离仅为 proxy，没有皮肤表面/力数据，不能宣称物理因果已证明。
5. **扩散**：复用原 ReGenNet 的 GaussianDiffusion、余弦 1000 步和 START_X 目标；对新残差 DCT 系数加噪。同一个图去噪器同时训练确定性端点（t=999、x_T=0）与随机 t 的去噪 MSE，确定性端点是明确监督的部署模式，不伪装成随机生成样本。训练仅使用 train 的统计量；DDIM 采样包含 0/999，关闭 x0 截断。独立报告固定 seed 单样本、NFE20/50 与点预测，禁止 GT 挑样。

这与旧 Track B 的区别：非全连接 token Transformer；显式类型图和因果累积事件特征；显式双腿相位流；更平滑残差起步；确定性端点同步受物理/相位/接触损失约束。随机采样不因点预测获益就自动采纳。

## 预登记矩阵与判据

H-val 协议：train 1709 / val 247；`manifest_subjval_seed0.json` 和 `ntu2p_xyz_seq_cache_subjval`。参照 `ntu2p_v2subj_A6-F-A5f0.05-A4-GH0.5-FD2_s{i}_10000/ema/model000010000.pt`。

| 代号 | 新模块 | 作用 |
|---|---|---|
| C0 | 无新增，既有 v2+FD2 | 当前主线参照 |
| C1 | 时间纠正器，关闭接触图/相位/扩散 | 额外监督/容量对照 |
| C2 | 图纠正器+接触监督 | 验证手—身体关系收益 |
| C3 | C2+双腿相位流 | 验证步态收益 |
| C4 | C3+扩散联合训练 | 验证扩散增量 |

先 seed0 × 5000 step 同预算筛选，所有候选同 lr=3e-4、batch=8、EMA=0.999、终点权重；至多 2 个有潜力的配置再 10000 step × 3 seed（重新从同一先验初始化，终点报告，不能选最好 checkpoint）。单卡按吞吐决定两个候选并发或串行；研究/诊断并行。

点预测采纳要求：三项 L2 不劣（均值各 ≤参照 1.005×），mpjpe 均值改善 ≥0.8%，或 L2 持平且定向自然度显著改善（步数差距或滑行帧比改善 ≥10%、接触距离误差改善 ≥10%，至少一个）；骨长相对误差 ≤1e-5，首帧 ≤1e-6；jerk ≤1.2×、穿地 ≤参照+0.01、dct_high ≤max(1.2×参照,0.05)，早期 gait corr 不低于参照−0.05；审查图不得出现新瞬移、弓步/穿插。候选部分收益但另一核心目标失败时明确标注，不能说两项均解决。

扩散增量要求：C4 按同口径优于 C3，才能声称扩散改善点预测。随机 DDIM 另按单样本 L2、脚滑、jerk、相位及概率质量评价；不通过仅保留研究开关，不推荐展示。

接触时序事件规则先由 train GT 确定；val 的推人仅 12 窗，报告样本数、距离/阈值敏感性、逐例时序和 bootstrap 置信区间。不能凭一个视频宣称普遍解决；若数据不支持稳定离散时序，主接触指标用连续距离曲线误差。

只有 H-val 采纳配置才按原协议 train 1758 × 3 seed 复训，然后一次 test；原 test 不参与调整。

## 实施顺序与验证

1. 文献核验、train/val 接触审计；新建设计审查/必要修订文档。
2. 新增共享几何/损失、组合式图扩散模型与 checkpoint 分派；旧入口默认行为不变。
3. 复用 v2 的主损失、归一化、EMA、GPU 数据采样、自然度与审查图；新增训练/实验驱动，不复制旧损失实现。
4. 有意义的结构验证：零头与先验相等；残差编码/解码互逆；初始速度连续；图确有对方依赖；接触记忆无未来泄露；图/腿/扩散梯度有限；checkpoint 复载相同；CUDA 不可用必须失败。
5. 冒烟与实测吞吐后完整候选训练、H-val 多指标与预固定案例（GT 选推人6/步行6/随机6，另全推人逐例），渲染检查。
6. 按预登记筛选/复现/采纳；失败如实报告。所有上下文与结果新建时间戳文件，同步 AGENTS.md，不改 CLAUDE.md 或历史文档。

## 取舍与风险

冻结先验降低实验成本且保持对照，但训练集先验误差偏小，纠正器可能过拟合；H-val 验证直接决定，不引入泄露。点预测修正不是 OOF 分布生成，随机采样需单独证明质量。16 阶表达可能限制极短接触；逐帧图看全预测序列时整体仍非因果生成器，只有事件记忆严格按时间累计。单卡与小接触样本数限制新颖性和统计外推，必须保留负结果。
