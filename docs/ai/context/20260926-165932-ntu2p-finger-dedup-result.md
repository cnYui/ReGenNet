# NTU2P 手指损失去重（FD）：结果（下一步候选第 2 批）

动机见 `docs/ai/context/20260926-005610-ntu2p-v2-final-result.md` 第 4、7 节：
- 刚体手下，30 个手指关节约等于把手腕误差复制 15 倍，占 A6 总 loss 的 81%，腿只占 7.7%；
- v2 在 test 上的滑行帧比比 A0 高 16%。

选型用第 1 批建立的受试者留出协议（`docs/ai/context/20260926-162912-ntu2p-subject-holdout-val-result.md`）。

## 实现

`train/train_ntu2p_v2.py` 新增 `--loss_joint_subset {all, hand2, hand5}`，默认 `all`，此时直接返回原张量，训练与之前逐位相同。

- 只作用于 s2_5 主损失及其 copy-last 归一化常数；脚接触、步态等额外项仍用全部 55 个关节。
- 子集保留身体 25 个关节（索引不变，交互项引用的手腕索引依然有效），再加：
  - `hand2`：每只手的 index1、pinky1，足以确定刚体手的旋转；
  - `hand5`：每只手 5 根手指的第 1 节。
- 驱动增量为 `FD2` / `FD5`，属于自然度类增量：
  - 判据：L2 劣化 ≤ +0.5%，且步行 GT 站定帧脚速或滑行帧比至少改善 10%；
  - 允许放在步态 token 之后，参照即为完整主线。
