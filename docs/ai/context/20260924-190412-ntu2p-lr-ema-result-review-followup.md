# NTU2P LR/EMA 结果文档：PR #12 审查跟进（结论 6 措辞更正）

对象：`docs/ai/context/20260924-190149-ntu2p-lr-cosine-ema-result.md` 的结论 6。按仓库约定不修改已合并的上下文文档，更正记录在本文。

## 审查意见

结论 6 写道："平台期上的权重平均优于平台上任何单个点"。支撑它的证据只有一次比较：3 seed EMA 均值（test 0.1882）对 seed 0 一个 20000 step 原始权重终点（test 0.1929），而且比较是在 test 上做的。这不足以支持"任何单个点"这种全称说法。

## 更正后的表述

> const-EMA 在 10000 step 的 test mpjpe（3 seed 均值 0.1882）低于已观测到的 seed 0 单次 20000 step 原始权重终点（0.1929）。这只是参考对照，不是对"EMA 优于平台上所有单个 checkpoint"的验证：没有在 val 上逐点比较 EMA 与平台内各原始 checkpoint，也不能用 test 做这种比较。

同 seed、只在 val 上的逐点事实如下（见结果文档的 summary）：

- seed 0：EMA@10000 为 0.1751，原始权重 8000–10000 为 0.1780 / 0.1827 / 0.1849；
- seed 1：EMA 0.1737，原始权重 0.1811 / 0.1773 / 0.1824；
- seed 2：EMA 0.1765，原始权重 0.1837 / 0.1839 / 0.1817。

可以说在已观测的 8000–10000 各 checkpoint 上，EMA 终点都低于同 seed 的原始权重。更长范围（例如 Stage 3 的 8000–20000 平台）没有做 EMA，不作推断。

## 影响

只更正措辞，不影响采纳判断与主数字：采纳依据是预登记的 val 规则（J、L、gate），与结论 6 无关。AGENTS.md 中未引用该表述，只增加本文的引用。
