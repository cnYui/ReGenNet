# JiT 流第 1 阶段（H-val 筛选）结果

设计与预登记：`20261018-201532-ntu2p-jit-flow-rl-design-and-plan.md`；t 分布修订：`20261018-205749-ntu2p-jitflow-t-distribution-amendment.md`。全部为 H-val（train 1709 / val 247）、seed0 × 5000 step、EMA 0.999 终点；参照 FD2 H-val EMA 10000 终点。未读取 test。

## 结论

1. **提分**：J3、J4 的确定性端点读出通过预登记提分规则。J4（时空图 Transformer + 自条件接触图注意力 + 跨人因果掩码 + JiT 流）mpjpe 0.16646（**−3.35%**），xyz_mse −2.8%，xyz_mae −3.6%，全部护栏通过；受试者簇配对 bootstrap 95% 区间 [−5.68, −0.89]%。J3（无接触图/因果）−2.52%，区间 [−4.79, +0.05]%。
2. **收益主要来自新去噪器结构，扩散训练的点预测增量不确定**：同结构去掉去噪损失（λ_flow=0）的对照 J3N −3.25%、J4N −2.50%；J3 有流反而比 J3N 差 0.76%，J4 有流比 J4N 好 0.88%，方向相反、都在 5000 step 单 seed 噪声（约 0.8%）内。流训练稳定带来的是更平滑：jerk 22.4–23.0 vs 无流 24.9–25.0（无流对照因此擦线未过 jerk ≤1.2× 护栏），穿地 0.035–0.038 vs 0.052。不能写成"扩散提分"。
3. **交互（手没到就躲）**：没有任何候选通过预登记交互规则（全动作三阈值 excess_antic ≤ 0.7× 参照且漏接触不增）。J4 端点 0.0363、J4 中位数 0.0453、J4 单样本 0.0564，均高于 FD2 的 0.0277；端点漏接触 60 vs 53。只在小子集上有描述性改善：0.25 m 阈值下推人（GT 6 个新接触）excess_antic FD2 0.221 → J4 端点 0.177 → J4 中位数 0.121（漏接触 3→2→1），击打类（11 个）0.127 → 0.105 → 0.074；样本少，不作结论。
4. **全部推人曲线（`analysis_stage1/all_pushing_contact_retreat.png`）**：FD2、J3、J4 及无流对照的 B 远离速度都从约 0.5 s 平滑抬升，GT 在接触后才陡升（例如 028：GT 2.1 s 才动，各确定性模型约 0.5 s 就开始）。换结构不改变这一点，与"确定性回归对接触时刻取平均"的机理一致；单样本反应陡峭但时刻随机。
5. **随机样本**：t 分布修订后单样本 mpjpe 0.361 → 0.239（J1），STG 去噪器更好（J4 0.214）；16 样本中位数/均值读出 0.174–0.191，都未优于 FD2。Energy Score J1–J4 为 0.233/0.222/0.210/0.208，劣于上一轮 C4（0.156）与 OOF bootstrap（0.128），概率质量没有进步。样本 jerk 52–58（GT 307，FD2 20）与 dct_high 未过护栏。
