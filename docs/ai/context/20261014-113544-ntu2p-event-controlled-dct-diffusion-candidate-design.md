## 需要改变的机制

当前软图把关系作为神经网络特征，再纠正一条已经预测出的完整未来。若先验 B 已提前后退，接触边可能永远不出现；在新增残差上乘接触门也挡不住先验里的后退。因此这个候选**替换 root 与腿的生成通道**，保留 v2 的规范系、DCT 表示、上身预测和骨长/刚体手约束。

三个彼此分开的控制量决定轨迹：

1. 运动路线：接触约束路线或自由路线。
2. 事件计划：起步时刻、先迈脚、左右站立/摆动状态、接触响应开始时刻。
3. 连续控制：root 速度、接触后响应速度、步长/摆高及手臂接近轨迹的低阶 DCT 系数。

这些量经同一个状态解码器生成确定性输出或随机样本。图关系不只调制隐藏层，它直接决定接触响应分量何时可以开启；脚状态不只是额外 loss，它决定哪只脚保留世界坐标锚点、哪只脚可以摆动。

## 可识别性与可兑现的保证

H-val 12 条推人中心窗中，四个固定距离阈值同时支持新发生接触→后退的只有 1 条；train 有 109 条推人序列，四阈值一致的重叠窗来自 28 条独立序列。现有骨架数据没有触觉、皮肤接触或外力记录，也没有同一人在“被碰/没被碰”两种干预下的配对动作。因此**无法识别真实自主运动与真实接触因果响应的唯一分解**。

本设计用“接触约束路线/自由路线”表示两种生成假设，不把它们当真实因果类别。明确成立的结构保证是：在接触约束路线中，新增响应速度在预测骨架代理接触之前严格为零；人物可以继续 obs 中已有的运动。它不等于人物 B 总速度为零，也不等于真实皮肤接触之后才动。

对用户最关心的“本来站定的 B 因 A 推而后退”片段，接触约束路线可以禁止在接触前生成新的退后速度。对主动躲避、早已在走、无可靠接触证据的片段，必须保留自由路线。自动模型选错路线时仍可能提前退让，需报告路线概率、逐例时序和错误，不能借自由路线隐藏问题。

## 1. 路线与接触响应解码

### 输入和最小网络

冻结同 seed、同协议的 v2+FD2，作为上身与自由路线的先验；新模块是约 0.3–0.6M 参数的共享 128 维 obs 编码器与小控制头，不再建立 44 节点×50 帧的大图去噪器。输入为 obs10 的 root/双腿/掌腕—躯干距离与速度、动作标签、先验手臂及 root 计划。A/B 权重共享并保留角色输入。条件中不得出现 GT future 或由它得到的真实接触/起步时刻。

两个路线在训练时都解码；推理时先输出路线概率。确定性 paired 预测选择 MAP 路线，概率模型按该分布采样；禁止把两路线逐帧平均，因为平均会把接触后的后退摊到接触之前，也会削弱迈步幅度。

自由路线仍输出个人速度控制，可以自主退让。它主要读本人的 obs 与动作；通过明确的路线选择接收对方条件，而不是把接触响应藏在一个无约束大跨人分支里。该限制不使它成为真正的因果自主运动模型，动作标签本身也可能让它预测退后。

### 接触约束路线

在受动者 B 的水平 root 通道，生成

`v_B(t) = v_cont(t | obs_B) + g(t | predicted_geometry) · h(t-τ_contact) · u_B(t-τ_contact)`。

- `v_cont` 是 obs 末 5 个平滑帧差速度的延续/轻衰减；初始最小版本不允许该项凭动作标签新启动退后。已在走的人可持续运动；obs 站定时它接近零。
- `u_B` 是事件中心时间的响应速度控制，由低阶 DCT 解码。接触之后按预测手—身体关系方向、响应幅度与时延调节；不把这当真实受力或动量守恒计算。
- `g` 是前缀事件锁存，只有候选轨迹的掌腕—躯干距离满足固定阈值、持续 3 帧后开启；开启后可在手离开时继续短时后退。它不能用持续极小 soft probability 的无限累积代替，否则几十帧的远距离接近也会提前触发。
- `h` 在响应开始后前 3 帧由 0 平滑升到 1，限制起步增量；root 由速度逐帧积分，不直接对 global IDCT 位移乘阶跃，避免触发时突然改变位置。

接触判据采用 `hand_body_distances` 的六段代理，在实施前固定 0.20 m 主阈值并全报 .15/.20/.25/.30 敏感性；不是由 val 选择一个能改善分数的阈值。训练使用相同硬事件逻辑；接触时刻的阶跃不给有效梯度，A 手的连续距离/接近曲线监督负责学习到达接触邻域。soft gate 只能作为明确的训练消融，不能训练时允许提前软响应、部署时硬截断却省略其分布差异。

逐帧先构造投影后的候选 A 手/B 躯干、计算接触，再积分该帧之后的 B 响应；不得用未来第 t+1 帧的接触触发第 t 帧运动。预测局部身体姿态可以在 root 尚未后退时准备/前倾，但新响应 root 不能绕过门。若最终骨架投影改变了用于触发的手/躯干几何，重新检查并记录违例；不能只在投影前证明保证。

### 不能只给先验加门

接触路线的 B root 从 obs 与上述控制器重建，**不加上先验未来 B root**。先验 B 的预测速度可作为网络条件，却不直接注入最终积分；否则其提前后退仍会保留。A 的上身保留先验并允许 12 阶 DCT 的小幅手/臂纠正，以修复先验根本没到达 B 的问题。B 的上身随重建 root 平移，再由原可微骨架投影保持骨长。

如果候选 A 始终未接触，接触路线就不生成新的退后；自由路线可覆盖数据中避让/接触代理失败的情况。这是可检查的失败行为，不能通过隐式小门/阈值漂移把它改成无条件后退。

### 路线监督及其局限

只把 train 中观测 B 基本站定、四阈值一致接触→后退的窗口标为高置信接触约束路线；mask 只用于训练标签，不作为推理输入。obs 已在退后或接触、GT 时序不稳定的窗口不给硬路线标签，使用轨迹混合损失与类别先验；不能仅凭“没有检出接触”就断言真实自主避让。非推人/踢人等动作优先保持自由路线，除非有单独校准与证据。

用观测与预测 A 手的条件训练路线分类、同路线内的轨迹误差；加弱标签交叉熵阻止全部塌缩到自由路线，但稀少高置信序列仍会使这一步不稳定。需要报告高置信 train 序列数/受试者数、各路线使用比例、后验和部署 MAP 的差异。这个分解具有结构可解释性，仍非统计识别的因果分解。

## 2. 起步、首脚与世界系脚锚

### obs10 能预测什么

审计显示 FD2 已在走的人 f1–10/f11–20 相位相关 0.909/0.833；起步者仅 0.328/0.402，先迈脚准确率 0.727。起步前两脚近乎静止时，obs10 无法唯一决定未来第一脚与起步时刻。因此输出路线内的联合分布 `p(τ_start, lead_foot, locomotion_mode | obs, action, predicted_contact_plan)`，不以一个相位标量平均所有未来。

最小标签：

- `τ_start` 用平滑 root 水平速度连续 3 帧超过 0.20 m/s 且后续 6 帧净位移 ≥5 cm 的首次时刻；不能与首脚偏离时刻混用。future50 内无事件为右删失类别，分类时必须保留。
- `lead_foot` 从低通左右踝前后分离及站立/摆动变化标注；没有明显变化时为未知，不迫使左右二选一。
- `locomotion_mode` 至少分步行/后退步行与自由腿动作；后者保留 v2 的腿预测，覆盖静止、踢、垫步、跳跃，防止所有动作被统一正弦化。
- 对已经在走的人，从 obs 的踝分离及脚相对 root 速度估计当前状态，不重新采样第一脚。

这些标签从 train future 获得是普通监督。评价使用 GT 子集可以，但推理时只能用预测状态。标签门限须先在 train 校准，不看本轮候选 val。

路线/首脚的硬选择本身没有连续梯度，使用独立分类/离散生存损失；连续控制在每条路线内受到可微 xyz/距离/腿损失约束。第一版不加入 Gumbel、强化学习或隐式优化来掩盖这一点。oracle 可以用 GT 事件测表示上限，但正式训练的最终输出损失与 val 必须用预测事件状态；若做 GT event teacher forcing，另登记暴露偏差、切换时程与纯部署状态对照，不能把 oracle 评分当预测效果。

### 状态解码器

步行路线采用允许双支撑的四状态：`双支撑/左摆右站/右摆左站/停止`。明确停止和自由腿动作，避免强制每段都左右交替。步行时若选择换脚，左右摆动状态按上一支撑脚交替；相位推进率、双支撑时长、步长与 root 速度共同预测，不用固定全数据统一频率。

站立脚在世界坐标保留锚点；摆动脚用零端点速度的样条从旧锚移动到新落脚点，落脚后更新该脚锚。root 速度和步长通过 `stride≈speed×stance_period` 的软一致性耦合，backward mode 使用有符号行进方向。根部静止时允许原地调整一步，但必须由单独事件而不是常开周期振荡触发。

接触路线中的起步 hazard 可以在接触前预测准备，但响应性 root 移动与相关迈步启动由接触门共同允许；自由路线保留自主起步。门影响新响应通道，不强行禁止 obs 里已在走的步态。

不要先输出腿 xyz 再用 world-foot loss 希望它自动站住。第一版直接对 hip-knee-ankle 使用已观测骨长的解析两骨 IK，把踝置于站立锚或摆动样条端点；膝弯曲方向用先验膝位置/个人前向确定，超伸时不得翻膝。foot 关节的局部方向复用观测/先验刚性足段。

root 的每步推进量必须落在当前支撑腿可达范围内：可将本帧拟议位移缩小为 `α Δroot, α∈[0,1]`，保持前一可行姿态作为回退，而不是额外移动 root 去追逐脚锚。这样不会因可达性投影在接触前凭空制造后退。最小版的步行控制固定观测 hip 相对 pelvis 布局，让该回退确实可行；这是牺牲骨盆摆动的取舍，若明显影响自然度再另开修订。

场景 up/地面和首脚锚只取 obs；训练 GT 接触标签可由 obs+GT 地面估计，但部署不能用 GT 地面。只约束水平锚比完全相信短 obs 的高度更稳妥；最终报告地面穿透、膝可达性/根步缩放比例、step count 与滑行指标，不把 IK 自动等同动力学自然度。

## 3. DCT 与原 ReGenNet 扩散的角色

保留 v2 的 DCT 上身预测。新低维控制由 DCT 表达：每人 root/响应速度的 8 阶系数、摆脚步长/摆幅的低阶系数、A 手臂接近纠正的 12 阶系数。DCT 控制经过状态解码器产生轨迹，接触/脚锚不需要由一个平滑全局位移基表示。局部事件的响应曲线以接触后时间为自变量，避免 global DCT 在事件前泄出响应。

扩散复用原 ReGenNet `GaussianDiffusion` 的余弦 1000 步、`q_sample`、`START_X` 与 DDIM，**目标改为 GT 直接提取/拟合的连续控制系数**。起步/首脚/路线为分类概率模型，随机采样时先采事件计划再扩散控制；不把 categorical event logits 当高斯物理量强行扩散。也不对冻结先验的整个人体 residual 重新做一遍 Track B。

与旧 Track B 的实质差别：

- 学 GT 的速度/落脚控制，而非 in-sample 底座的 full-body 残差分布；不需要假设 train 残差和部署残差尺度相同。
- 每个样本由同一接触门与脚锚状态解码，无论随机控制如何变化，响应通道在代理接触前仍为零，站立脚仍有世界坐标约束。
- 多模态集中在可解释的起步/首脚/响应幅度；同一事件计划内才做连续控制去噪，不用均值腿形去拟合两个相反首脚。
- 扩散只学习控制的不确定性，不用随机全身噪声打破运动开始连续性；关节骨长与刚体手沿用既有合法人体路径。

这些差别仍不能自动保证随机概率质量。抽取 GT 控制的规则与解码器存在表示误差，须先测 train oracle：给真实路线/事件/控制后能还原多少 xyz、起步时序和步态。若 IK/控制 oracle 就不能达到主线水平，不应直接训练神经模型补偿错误表示。

自由路线的 root 速度直接取 GT 差分；接触路线的 `u_B` 只能在高置信代理事件之后由 GT 速度减去规定的 `v_cont` 再拟合，接触前不为其伪造标签。这个确定的编码规则仍不是真实力/自主运动的分解，但其 target 不依赖一个已经拟合相同样本的神经先验，因而与旧 in-sample residual diffusion 的训练分布问题不同。

确定性分支输出显式监督的控制点估计，选择 MAP 事件计划；它不是扩散样本。扩散分支从标准高斯噪声开始，固定 seed、eta=0，报告 NFE20/50/K8。所有候选的控制监督与辅助前向次数匹配；C4 那种 clean-control 辅助任务是噪声对照，不能因为扩散多做一次监督就声称增益。

## 4. 最小实施顺序与预算

单张 3080 10GB、1709 条 train、109 条推人，不引入物理模拟器/新大型预训练模型，也不同时训练全身动作 token、力预测、皮肤接触与复杂 latent ODE。

1. **只做标签与 oracle**：统计 train 各事件/路线可信度、稳定序列数；离线提取 root 速度和足锚/样条控制，测试解析 IK 与事件积分的 oracle 误差。最小可复用新文件为一个事件标签工具与一个纯 torch 状态解码器。
2. **确定性控制器**：冻结 FD2，上身只开手臂小头；所有路线、状态和 DCT 控制头总新增参数目标 ≤0.6M；batch8，EMA.999，显式 cuda:0。先 train 200 step 冒烟，检查接触门前增量、站立锚误差、首帧/初速与膝可达性，然后按预登记 seed0 5000 step。
3. **匹配消融后扩散**：只有确定性事件/脚状态路线有证据时，加入控制系数扩散。同调用次数辅助 clean-target 与 q_sample 噪声对照，追加而不重复大模型训练。
4. **复现**：有潜力的最终方案最多一个 10000×3 seed；H-val 完成采纳后才按原协议复训×3 seed并一次 test。整个候选阶段预计 4×5000＋3×10000 个小控制器 step，实际 GPU 时间由冒烟测量登记，不预报吞吐。

最小可验证版先只实现推人接触路线的 B root 替换，保留所有腿/上身为 FD2 root-relative 轨迹；把一条候选 A 手路径向前/向后平移，验证预测代理接触时刻与 B 新响应起点同向移动，未接触时该通道为零、obs 已有 B 运动仍可延续。该版本不宣称解决脚滑，先证明接触机制确有行为约束，再投入脚状态/IK。实现难度的主项是 50 帧状态滚动、足锚与解析 IK、可达性回退及最终投影几何的一致性；小网络和 DCT/扩散调用复用现有组件，属于中等至较高实现复杂度，不能按新增一个 loss 的工作量估算。

## 5. 预登记消融与判据

| 代号 | 变化 | 验证问题 |
|---|---|---|
| E0 | 相同控制头、标签与损失；无响应门、无脚锚状态解码，保留通常轨迹头 | 监督与控制容量参照 |
| E1 | E0 + 接触路线替换 B root 与响应速度积分；脚仍用参照腿轨迹 | 接触事件机制是否改善提前反应 |
| E2 | E1 + 起步/首脚状态与世界系脚锚/IK | 步态同步是否改善且没有锁住非步行动作 |
| E3 | E2 + ReGenNet 控制系数 q_sample 去噪；E2 使用等调用 clean-control辅助任务 | 扩散是否超出更多控制监督的收益 |

所有 E0–E3 共享 obs/先验、数据采样、同动作采样权重、route/event/控制标签、连续手—身体/脚/腿/自然度损失与学习率、调用次数；结构关闭仍保留相同参数集合，记录实际有效 trainable 参数。E0 为容量/额外监督基线，而非与 v2 比后把任何收益归为新结构。

使用既有 H-val 选型约束：三项 L2 均值各 ≤主线1.005×；平均 mpjpe 改善≥0.8%，或在 L2 持平时起步步态/接触连续几何有≥10%工程改善。双目标分别报告，只有一项有效就只能声称局部改进。沿用骨长、jerk、穿地、dct_high 与 moving 早期相位护栏，并单列 starting 指标。

接触：主指标为连续六段掌腕—身体最近距离 RMSE、受动者 root 速度曲线误差；全报固定四阈值×两退后速度的事件 bias/MAE、缺失数、路线选择与各例。已知有效中心窗很少，事件不作统计稳定的硬 gate。结构检查可以要求接触约束路线的响应增量在最终投影代理接触前为零，但这只验证实现，不是分数，也不是全数据物理保证。

步态：starting/moving 分开报 onset MAE与删失数、先迈脚 Brier/准确率、前0.5/1.0s相位相关、step-count gap、root—foot相对速度、站立脚自滑/GT站定脚速度；对非步行/踢腿/垫步逐例看新增误迈步。推理 onset 不能用 GT 分离第一次变化来触发。

随机样本：固定 seed 单样本的 xyz、jerk/穿地/脚滑与事件指标；K8 的 Energy Score、先迈脚 Brier/起步时刻分布与覆盖。对照为同事件标签条件下的 train 真实控制 bootstrap、确定性 E2；不按 GT 挑最好首脚/最好轨迹。没有概率质量增量时，扩散只是研究开关。

## 6. 文献边界与放弃条件

下列论文已在本轮由官方原文获取并核验，均不是这个候选的原创组件：

- [HumanMAC，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Chen_HumanMAC_Masked_Motion_Completion_for_Human_Motion_Prediction_ICCV_2023_paper.html)：DCT/频域运动与扩散已有先例。
- [InterDiff，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Xu_InterDiff_Generating_3D_Human-Object_Interactions_with_Physics-Informed_Diffusion_ICCV_2023_paper.html)：接触参考系与物理先验纠正已存在，原文也说明 skeletal HOI 接触定义困难。
- [ReGenNet，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Xu_ReGenNet_Towards_Human_Action-Reaction_Synthesis_CVPR_2024_paper.html)：动作—反应条件生成已有；此处 actor future 也预测，不能把 GT actor future 作为隐含推理条件。
- [POMP，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Ji_POMP_Physics-consistent_Motion_Generative_Model_through_Phase_Manifolds_CVPR_2025_paper.html)：相位流形指导扩散与动力学约束已有，不能把“phase+diffusion”称首创。
- [Ponimator，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Liu_Ponimator_Unfolding_Interactive_Pose_for_Versatile_Human-human_Interaction_Animation_ICCV_2025_paper.html)：近接触双人姿态锚定与前后反应已有。
- [Interact2Ar，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Ruiz-Ponce_Interact2Ar_Full-Body_Human-Human_Interaction_Generation_via_Autoregressive_Diffusion_Models_CVPR_2026_paper.html)：逐段自回归的双人扩散与适应性生成已有。

检索/原文获取日期为 2026-10-14；来源元数据在 `results/forecasting/ntu120_label/ntu2p_graphdiff_research/search_selected.json`、`search_2026_selected.json`、`search_fulltext.json`。候选潜在贡献只能表述为当前短观测预测任务中对接触事件和起步脚状态的具体可验证组合，不预承诺无人做过。

放弃条件：oracle 不能保留现有准确度/骨长/膝自然度；train 可靠路线严重集中于极少受试者；路线分类塌缩或 H-val 自由路线几乎吞掉所有推人；脚锚导致root系统性滞后/膝翻转；控制扩散概率质量不如 bootstrap。出现这些结果，应报告数据与表示限制，不通过再加更多隐式自由分支消解本候选的结构假设。
