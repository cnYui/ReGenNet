# NTU2P 图扩散结构验证计划与审查修订核对

本文件在新增 `scripts/check_ntu2p_graphdiff.py` 前创建。结构验证复用既有 H-val 缓存、v2+FD2 prior 和旧残差编解码工具；不训练完整候选，不以 val 数字改架构。只维护该脚本，不修改其它代理负责的模型/训练文件。

## 审查修订核对

修订依据：`20261014-111722-ntu2p-contact-graph-diffusion-preregistration-amendment.md`。

- [DA-DECISION: Score 5/5 | ACTION: Concede | REASON: C1–C4 统一物理损失，均两次纠正器调用；第二项均监督同一系数目标，C4 唯一增加 q_sample 输入加噪，解决 M1 主混杂]
- [DA-DECISION: Score 4/5 | ACTION: Hold | REASON: 最终投影轨迹重算监督解决接触监督位置，但冻结 prior 的事件仍可能错时；报告其与最终曲线的一致性并限定关系图解释即可推进]
- [DA-DECISION: Score 5/5 | ACTION: Concede | REASON: 离散接触事件退为全阈值诊断、连续距离为主指标，并承认数据不能硬识别所有反应顺序，解决 M5 采纳过度]
- M4 已修订为只保证首帧零纠正，不再承诺完整离散速度；结构检查仍需记录基条件数、投影后的首帧与起步增量、oracle 前 10 帧重建误差。
- M2/M7 保留明确概率边界；随机扩散另评，不因端点回归获益自动采纳。

## 验证内容

1. 所有 C1–C4 零初始化输出与冻结 prior 最大差在浮点容差内；prior 保持 eval、requires_grad=False。
2. K=16 smoothstep 基首帧严格零；encode(decode(c))≈c，基满秩；不要求任意 GT 残差精确往返。
3. 最终投影输出首帧、骨长、刚体手不被残差破坏；记录 oracle 全程/前 10 帧的可表达误差与首个离散纠正速度。
4. START_X/1000 步余弦 q_sample 对有限系数输出有限；随机时间、端点与模型同形状。
5. 零 head 更新一次后主干、图消息、腿流获得有限非零梯度；冻结 prior 不产生梯度。
6. 接触累积记忆修改未来区段后，过去区段保持相同；不要把整个双向时序模型误判为因果。
7. 固定几何条件，对方特征扰动能影响本人的图输出；需打开零 head，避免零初始化掩盖依赖。
8. 用实际 checkpoint 字典与 loader 回载后确定性输出一致；config 的图/相位/扩散开关被保存。
9. 新训练入口在 cpu 无显式 smoke 授权及 CUDA 不可用场景必须抛错，不发生静默回退。

## 执行与取舍

测试默认在 CPU、固定 seed 和 2–4 个真实窗口执行，避免抢占整轮训练 GPU；可显式指定 cuda:0 复核。失败即非零退出并写 JSON。新模块 API 在文件出现后按真实接口对齐，不用吞异常的宽泛适配掩盖错误。候选评分、对照和实际视频审查由父代理完成。
